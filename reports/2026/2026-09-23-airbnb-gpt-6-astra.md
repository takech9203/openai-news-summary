## 概要

Airbnb は OpenAI との新たな契約に基づき、エンジニアリングチームと製品開発チームに対して GPT-6 Astra を含む OpenAI フロンティアモデルへのアクセスを拡大した。今回の拡大は、Airbnb による Codex の活用と OpenAI との長年にわたる協業を基盤としたものである。

新契約により、Airbnb は OpenAI API と Amazon Bedrock を通じて OpenAI モデルへのより広範なアクセスを獲得する。この発表は、開発者・ビルダー・エンタープライズの間で GPT-6 Astra の採用が加速するタイミングで行われた。これらの企業の多くは、すでに GPT-5.6 Terra および Luna の改善された価格性能比と効率性の恩恵を受けていた。

## 主な内容

### Codex と社内 AI アシスタントの活用

Airbnb のエンジニアは、ソフトウェアの作成やリモート AI エージェントの構築のために社内 AI アシスタントを利用している。このアシスタントは Codex と、GPT-5.6 Sol、Terra、Luna などのモデルを基盤としている。

### GPT-6 Astra による初期成果

Airbnb における GPT-6 Astra の初期利用では、コーディングを超えた領域でも強力な成果が確認されている。

- **困難なバグの追跡**: Astra はエンジニアが難しいバグを特定する作業を加速する
- **システム設計の策定**: システムデザインの形成を支援する
- **エンジニアリングアプローチのブレインストーミング**: 技術的な方針検討を支援する
- **非コーディング業務での効率化**: 戦略文書などの非コーディング業務を対象としたテストでは、あるユーザーは他のモデルでは 20 回以上のやり取りが必要だったところ、3-4 回のパスで満足のいくアウトプットに到達したと報告している

### 経営陣のコメント

Airbnb の CTO である Ahmad Al-Dahle 氏は次のように述べている。

> 「当社の開発チームは 1 年前と比較して約 80% 多くの機能を出荷しています。GPT-6 Astra を含む OpenAI のフロンティアモデルは、この勢いを維持し、より良い製品をより速く構築するのに役立つ開発者ツールの重要な要素です」

OpenAI の CRO である Dali Rajic 氏は次のように述べている。

> 「Airbnb は AI を活用してソフトウェアの構築方法を再考してきました。GPT-6 Astra のようなモデルへのアクセス拡大により、同社のチームはアイデアからプロダクションへとより速く移行するための、さらに強力なツールを手にします。Airbnb がエンジニアリングと、数百万のゲストとホストのために構築する体験全体に OpenAI の能力を活用する中で、協業をさらに深められることを誇りに思います」

### マーケットプレイス全体での AI 活用

Airbnb はエンジニアリング以外でも OpenAI モデルを活用しており、以下の領域での体験を支えている。

- **検索**: ゲストが何を探しているかをより深く理解する
- **不正防止**: 不正の可能性があるコンテンツや請求を特定する
- **ゲスト・ホストサポート**: 旅行の計画変更時にゲストを支援する
- **保険請求**: ホストへの保険金支払いをより迅速かつ簡単にする

### 今後の展開

Airbnb は住宅、サービス、体験、空港送迎、レンタカーなど、旅行のより多くの要素を 1 つのアプリに統合しようとしている。OpenAI のフロンティアモデルは、それらの機能を構築するチームに対して、より速く前進し、次に来るものを探求するための強力なツールを提供する。

## 開発者への影響

- **エンタープライズでの GPT-6 Astra 採用事例**: 大規模テック企業がフロンティアモデルを開発ワークフロー全体に組み込む具体例として参考になる
- **マルチチャネルでのモデル提供**: OpenAI API に加えて Amazon Bedrock 経由でも OpenAI モデルへアクセスできる構成が示されている
- **コーディング以外への適用**: バグ追跡、システム設計、戦略文書作成など、コード生成にとどまらない活用範囲が実証されている
- **生産性向上の定量的指標**: 機能出荷数が前年比約 80% 増という数値は、AI 導入効果の参考指標となる
