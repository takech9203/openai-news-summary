💡 概要

2026 年 9 月 8 日、OpenAI は API Changelog にて 2 つのアップデートを発表した。Responses API における Prompt Cache Diagnostics の一般提供 (GA) 開始と、画像生成モデル GPT Image 2.5 Sunburst / Flare のリリースである。

🔍

Prompt Cache Diagnostics が GA 化

Responses API で一般提供を開始。GPT-5.6 以降のサポート対象モデルで、キャッシュ再利用状況の比較・キャッシュミスの原因特定・トラブルシューティングガイダンスの参照が可能に。

🎨

GPT Image 2.5 Sunburst / Flare をリリース

Sunburst は編集精度を最重視、Flare は高速かつ高品質な日常的画像生成向け。Image API と Responses API の画像生成ツール経由で利用できる。

⚙️

新しい品質設定 xhigh / max に対応

GPT Image 2.5 の両モデルとも、新しい xhigh と max の品質設定をサポートし、用途に応じた品質とコストのバランス調整が可能になった。

💰

料金は GPT Image 2 と同一

GPT Image 2 と同じトークンレートが適用されるため、既存の画像生成ワークフローからモデル名の変更だけで移行しやすい。

📰 主な内容

🔍 Prompt Cache Diagnostics の GA 化

Responses API で Prompt Cache Diagnostics が一般提供 (GA) となった。対応モデルは GPT-5.6 以降のサポート対象モデルである。

公式 Changelog より "Compare cache reuse against a previous response, identify reasons for cache misses, and follow troubleshooting guidance"
  • キャッシュ再利用の比較: 過去のレスポンスと比較して、プロンプトキャッシュがどの程度再利用されたかを確認できる
  • キャッシュミスの原因特定: キャッシュヒットしなかった理由 (プロンプト先頭部分の変更など) を診断情報として取得できる
  • トラブルシューティングガイダンス: 診断結果に基づく改善ガイダンスに従うことで、キャッシュ再利用率を高めコストとレイテンシを削減できる

プロンプトキャッシュはプロンプトの共通プレフィックスを再利用することで入力トークンのコストとレイテンシを削減する仕組みだが、これまではキャッシュミスが発生した際にその原因を特定する手段が限られていた。GA 化により、本番環境でも安心して診断機能を活用できるようになった。

🎨 GPT Image 2.5 Sunburst / GPT Image 2.5 Flare のリリース

画像生成・編集向けの新モデル 2 種がリリースされた。

モデル特徴主な用途
gpt-image-2.5-sunburst編集精度を最重視精密な画像編集ワークフロー
gpt-image-2.5-flare高速かつ高品質日常的な画像生成
公式 Changelog より "Use Sunburst for workflows where editing precision matters most, or Flare for fast, high-quality everyday image generation"
  • 利用可能な API: Image API (v1/images) および Responses API (v1/responses) の画像生成ツール
  • 品質設定: 両モデルとも新しい xhigh と max の品質設定に対応
  • 料金: GPT Image 2 と同じトークンレートを使用

✨ 主要機能

🔁 キャッシュ再利用の比較

過去のレスポンスと比較し、プロンプトキャッシュの再利用状況をデータで確認。改善効果を定量的に把握できる。

🩺 キャッシュミス診断

キャッシュヒットしなかった理由 (プロンプト先頭部分の変更など) を診断情報として取得し、原因を特定できる。

📖 改善ガイダンス

診断結果に基づくトラブルシューティングガイダンスに従い、キャッシュ再利用率を高めてコストとレイテンシを削減。

🌅 GPT Image 2.5 Sunburst

編集精度を最重視したモデル。被写体を維持しながら背景だけを変更するなど、精密な画像編集ワークフローに最適。

⚡ GPT Image 2.5 Flare

高速かつ高品質な画像生成モデル。日常的な画像生成タスクをスピーディにこなす。

🎚️ xhigh / max 品質設定

新しい 2 段階の高品質設定により、用途に応じた品質とコストのバランス調整が可能に。料金は GPT Image 2 と同一。

🛠️ 技術的な詳細 (API 変更点)

🔍 Prompt Cache Diagnostics の利用イメージ

Responses API のレスポンスに含まれるキャッシュ関連情報を参照し、過去のレスポンスと比較してキャッシュミスの原因を診断する。

Python Prompt Cache Diagnostics の利用例 
from openai import OpenAI

client = OpenAI()

# 1 回目のリクエスト (キャッシュのベースライン)
first = client.responses.create(
    model="gpt-5.6",
    input=[
        {"role": "developer", "content": LONG_SYSTEM_PROMPT},
        {"role": "user", "content": "ユーザーからの質問 1"},
    ],
)

# 2 回目のリクエスト (キャッシュ再利用を期待)
second = client.responses.create(
    model="gpt-5.6",
    input=[
        {"role": "developer", "content": LONG_SYSTEM_PROMPT},
        {"role": "user", "content": "ユーザーからの質問 2"},
    ],
)

# キャッシュ利用状況の確認
print(second.usage.input_tokens_details.cached_tokens)

キャッシュヒット率が低い場合は、診断情報をもとにプロンプト構成 (静的な部分を先頭に、動的な部分を末尾に配置するなど) を見直すことで再利用率を改善できる。

🎨 GPT Image 2.5 の利用例

Python Image API での画像生成・編集 
from openai import OpenAI

client = OpenAI()

# Flare: 高速な日常用途の画像生成
result = client.images.generate(
    model="gpt-image-2.5-flare",
    prompt="夕焼けの富士山と桜の風景",
    quality="xhigh",  # 新しい品質設定: xhigh / max
)

# Sunburst: 編集精度が重要なワークフロー
edited = client.images.edit(
    model="gpt-image-2.5-sunburst",
    image=open("input.png", "rb"),
    prompt="背景を星空に変更し、被写体はそのまま維持する",
    quality="max",
)

Responses API の画像生成ツール経由でも利用できる。

Python Responses API の画像生成ツール経由での利用 
response = client.responses.create(
    model="gpt-5.6",
    input="製品ロゴのコンセプト画像を生成してください",
    tools=[{"type": "image_generation", "model": "gpt-image-2.5-flare"}],
)

📝 まとめ

2026 年 9 月 8 日の API アップデートでは、Responses API の Prompt Cache Diagnostics が GA 化され (GPT-5.6 以降対応)、キャッシュミスの原因特定と再利用改善が本番環境で可能になった。また、画像生成モデル GPT Image 2.5 Sunburst (編集精度重視) と GPT Image 2.5 Flare (高速・高品質) がリリースされ、新しい xhigh / max 品質設定に対応した。料金は GPT Image 2 と同一のため、既存ワークフローからの移行障壁は低い。コスト最適化と画像生成品質の両面で、開発者にとって実用性の高いアップデートである。
