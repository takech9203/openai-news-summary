🛡️ 信頼性の高いマルチテナンシー

単一のストレージ基盤を複数のサービス・ワークロード (テナント) で共有するための設計。一般に以下の課題への対応が必要。

  • 「ノイジーネイバー」問題の抑制
  • テナントごとのクォータ、レート制限、優先度制御
  • 障害の影響範囲 (ブラストラディウス) の限定
具体的な分離手法は公式記事での確認が必要

🌐 グローバルキャッシュ

ユーザーに近いロケーションでキャッシュを提供し、レイテンシ削減とバックエンド負荷軽減を両立。会話履歴の表示・継続など読み取りが支配的な ChatGPT のワークロードで、読み取りを 12 倍高速化。

整合性モデル・無効化戦略・ヒット率は公式情報での確認が必要

🗄️ Azure Cosmos DB

Microsoft Azure のグローバル分散型マルチモデルデータベース。一般に以下の特性で知られる。

  • 複数リージョンへのレプリケーションとマルチリージョン書き込み
  • 複数の整合性レベル (strong から eventual まで)
  • パーティションキーに基づく水平スケーリング
API 種類・整合性レベル・パーティション設計は公式記事での確認が必要
