API アップデート

Responses API に GPT-6.1 Sol 向け Ultrafast モードを追加

📅 2026-10-08 | ソース: OpenAI API Changelog

service_tier: "ultrafast" の指定だけで、GPT-6.1 Sol の高速推論が全 API ユーザーに開放。米国に加えて EU データレジデンシーにも新規対応。

概要 : キーポイント

⚡

GPT-6.1 Sol が Ultrafast モードに対応

Responses API (v1/responses) で gpt-6.1-sol 向けの Ultrafast モードが利用可能に。出力トークン生成間のレイテンシ (inter-token latency) を大幅に短縮した高速推論を提供する。

🔧

パラメータ 1 つで利用可能

リクエストボディの service_tier パラメータに "ultrafast" を指定するだけ。既存コードの変更は最小限で済む。

🌍

EU データレジデンシーに新規対応

グローバル処理と米国データレジデンシーに加え、EU データレジデンシーに新たに対応。GDPR などの規制要件下でも Ultrafast モードを採用できる。

👥

全 API ユーザーが利用可能

レート制限はあるものの、全 API ユーザーに開放。9 月 29 日の GPT-6 Astra 向け先行リリースから提供範囲が拡大した。

💰

専用の Ultrafast pricing を適用

Ultrafast モードには標準価格とは別の専用価格が適用される。詳細は料金ページでの事前確認が必要。

Before / After : 先行リリースとの比較

Before (2026-09-29 / gpt-6-astra)

  • 🤖 対象モデル: GPT-6 Astra のみ
  • 👤 提供範囲: API カスタマー
  • 🇺🇸 米国データレジデンシー: 対応
  • 🚫 EU データレジデンシー: 非対応
  • ⏱️ レート制限: あり

After (2026-10-08 / gpt-6.1-sol)

  • 🤖 対象モデル: GPT-6.1 Sol に拡大
  • 👥 提供範囲: 全 API ユーザー
  • 🇺🇸 米国データレジデンシー: 対応
  • 🇪🇺 EU データレジデンシー: 対応 (新規)
  • ⏱️ レート制限: あり
💡 GPT-6.1 Sol 自体も 2026 年 9 月 29 日リリースのモデルで、GPT-6 Astra より低コストに複雑なコーディングやプロフェッショナル業務をこなす位置づけ。標準価格は入力 272K トークンまでの場合、100 万トークンあたり入力 $2 / キャッシュ入力 $0.10 / キャッシュ書き込み $2.50 / 出力 $10 (Ultrafast モードには別途専用価格が適用)。

主要機能

⚡ 低レイテンシ推論

出力トークン生成間の時間 (inter-token latency) を短縮することに特化した高速推論向けサービスティア。体感速度が UX を左右するアプリに最適。

🎯 対象モデルと API

対象モデルは gpt-6.1-sol、対象 API は Responses API (v1/responses)。リクエストに service_tier: "ultrafast" を指定して利用する。

🌍 データレジデンシー

グローバル処理に加え、米国および EU のデータレジデンシーに対応。EU 対応は今回のアップデートで新たに追加された。

🔁 レスポンスでティアを確認

このティアで処理されたレスポンスには service_tier: "ultrafast" が返却される。実際の処理モードはリクエスト指定値と異なる場合がある点に注意。

💰 専用の Ultrafast pricing

Ultrafast モードには専用価格が適用される。標準価格とは異なるため、本番導入前に料金ページで確認が必要。

API 変更点 : service_tier パラメータ

公式 API リファレンスによると、service_tier パラメータには以下の値を指定できる。

値 説明
auto プロジェクト設定で構成されたサービスティアで処理 (未設定時のデフォルト動作)
default 選択したモデルの標準的な価格・性能で処理
flex Flex Processing ティアで処理 (低コスト・レイテンシ許容)
scale Scale ティアで処理
fast / priority リクエスト単位で Fast mode にオプトイン (レスポンスではいずれも priority と表示)
ultrafast アクセス制御付きの Ultrafast Processing ティアで処理 (今回 GPT-6.1 Sol に対応)
⚠️ レスポンスボディの service_tier には、実際にリクエストの処理に使われた処理モードが返却され、リクエストで指定した値と異なる場合がある。

技術詳細 : コードサンプル

Python GPT-6.1 Sol の Ultrafast モード利用例 
from openai import OpenAI

client = OpenAI()

response = client.responses.create(
    model="gpt-6.1-sol",
    service_tier="ultrafast",
    input="リアルタイムチャット向けに短い応答を生成してください。",
)

print(response.output_text)
# 実際に適用されたティアを確認
print(response.service_tier)  # => "ultrafast"
Bash cURL での呼び出し例 
curl https://api.openai.com/v1/responses \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-6.1-sol",
    "service_tier": "ultrafast",
    "input": "Hello!"
  }'

ユースケース / 開発者への影響

🗣️ リアルタイムチャット・音声対話・コーディング支援

トークン生成速度が UX を左右するアプリケーションで、GPT-6.1 Sol の品質と Ultrafast の速度を両立できる。低レイテンシ用途の選択肢が広がる。

🇪🇺 EU リージョン要件下でのプロダクト運用

GDPR などの規制で EU データレジデンシーが必須の組織でも Ultrafast モードを採用できるようになり、欧州向けプロダクトでの利用障壁が解消された。

💰 「高速だが比較的安価」なコスト最適化構成

GPT-6.1 Sol は GPT-6 Astra より低コストなモデルのため、速度とコストを両立した構成が可能。ただし Ultrafast は専用価格が適用されるため、料金ページでの事前確認が必要。

🛡️ レート制限へのフォールバック実装と容易な移行

レート制限があるため、本番投入時は service_tier を default に切り替えるなどのフォールバック実装を検討するとよい。既存の Responses API 呼び出しにパラメータを 1 つ追加するだけで利用でき、移行は容易。

まとめ

2026 年 10 月 8 日のアップデートにより、Responses API の Ultrafast モード (service_tier: "ultrafast") が GPT-6.1 Sol でも利用可能になった。9 月 29 日の GPT-6 Astra 向け先行リリースと比べ、対象モデルの拡大に加えて EU データレジデンシーに新たに対応した点が大きな進展である。低レイテンシが求められるアプリケーションを EU リージョン要件下で運用する開発者にとって、有力な選択肢となるアップデートである。
