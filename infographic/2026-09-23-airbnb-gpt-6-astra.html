Airbnb が GPT-6 Astra と OpenAI フロンティアモデルへのアクセスを拡大

OpenAI との新契約により、エンジニアリングチームと製品開発チームが OpenAI API と Amazon Bedrock を通じて GPT-6 Astra を含むフロンティアモデルへの広範なアクセスを獲得

📅 2026-09-23 | 出典: OpenAI News

概要

Airbnb は OpenAI との新たな契約に基づき、エンジニアリングチームと製品開発チームに対して GPT-6 Astra を含む OpenAI フロンティアモデルへのアクセスを拡大した。今回の拡大は、Airbnb による Codex の活用と OpenAI との長年にわたる協業を基盤としたものである。この発表は、開発者・ビルダー・エンタープライズの間で GPT-6 Astra の採用が加速するタイミングで行われた。

🤝

新契約でフロンティアモデルへのアクセスを拡大

GPT-6 Astra を含む OpenAI フロンティアモデルへのアクセスを、エンジニアリング・製品開発チーム全体に拡大。Codex 活用と長年の協業が基盤。

🌐

OpenAI API と Amazon Bedrock の 2 チャネルで提供

新契約により、OpenAI API と Amazon Bedrock の両方を通じて OpenAI モデルへのより広範なアクセスを獲得する。

🚀

機能出荷数が前年比約 80% 増

開発チームは 1 年前と比較して約 80% 多くの機能を出荷。OpenAI のフロンティアモデルがこの勢いを支える開発者ツールの重要な要素。

🧠

コーディングを超えた領域で GPT-6 Astra が成果

バグ追跡、システム設計、ブレインストーミング、戦略文書作成など、コード生成にとどまらない活用で初期成果を確認。

📈

GPT-5.6 系の価格性能比の恩恵が採用を後押し

GPT-6 Astra を採用する企業の多くは、すでに GPT-5.6 Terra および Luna の改善された価格性能比と効率性の恩恵を受けていた。

主なポイント

🛠️ Codex と社内 AI アシスタントの活用

Airbnb のエンジニアは、ソフトウェアの作成やリモート AI エージェントの構築のために社内 AI アシスタントを利用。このアシスタントは Codex と、GPT-5.6 Sol、Terra、Luna などのモデルを基盤としている。

🐛 困難なバグの追跡を加速

GPT-6 Astra はエンジニアが難しいバグを特定する作業を加速する。初期利用でコーディングを超えた領域でも強力な成果が確認されている。

📐 システム設計の策定を支援

システムデザインの形成を支援し、エンジニアリングアプローチのブレインストーミングなど技術的な方針検討にも活用されている。

📝 非コーディング業務での効率化

戦略文書などの非コーディング業務を対象としたテストでは、あるユーザーは他のモデルでは 20 回以上のやり取りが必要だったところ、3-4 回のパスで満足のいくアウトプットに到達したと報告。

✈️ 今後の展開: 旅行体験を 1 つのアプリに統合

Airbnb は住宅、サービス、体験、空港送迎、レンタカーなど、旅行のより多くの要素を 1 つのアプリに統合しようとしている。フロンティアモデルは、それらを構築するチームがより速く前進し、次に来るものを探求するための強力なツールを提供する。

「当社の開発チームは 1 年前と比較して約 80% 多くの機能を出荷しています。GPT-6 Astra を含む OpenAI のフロンティアモデルは、この勢いを維持し、より良い製品をより速く構築するのに役立つ開発者ツールの重要な要素です」

— Ahmad Al-Dahle 氏、CTO、Airbnb

「Airbnb は AI を活用してソフトウェアの構築方法を再考してきました。GPT-6 Astra のようなモデルへのアクセス拡大により、同社のチームはアイデアからプロダクションへとより速く移行するための、さらに強力なツールを手にします。Airbnb がエンジニアリングと、数百万のゲストとホストのために構築する体験全体に OpenAI の能力を活用する中で、協業をさらに深められることを誇りに思います」

— Dali Rajic 氏、CRO、OpenAI

マーケットプレイス全体での AI 活用

Airbnb はエンジニアリング以外でも OpenAI モデルを活用しており、以下の領域での体験を支えている。

🔍 検索

ゲストが何を探しているかをより深く理解する。

🛡️ 不正防止

不正の可能性があるコンテンツや請求を特定する。

💬 ゲスト・ホストサポート

旅行の計画変更時にゲストを支援する。

📄 保険請求

ホストへの保険金支払いをより迅速かつ簡単にする。

ユースケース / 開発者への影響

🏢 エンタープライズでの GPT-6 Astra 採用事例

大規模テック企業がフロンティアモデルを開発ワークフロー全体に組み込む具体例として参考になる。機能出荷数が前年比約 80% 増という数値は、AI 導入効果の定量的な参考指標となる。

🌐 マルチチャネルでのモデル提供

OpenAI API に加えて Amazon Bedrock 経由でも OpenAI モデルへアクセスできる構成が示されており、既存のクラウド基盤を活かしたモデル導入の選択肢が広がる。

🧩 コーディング以外への適用

バグ追跡、システム設計、戦略文書作成など、コード生成にとどまらない活用範囲が実証されている。エンジニアリング業務全体での AI 活用を検討する際の実例となる。

まとめ

Airbnb は新契約により、OpenAI API と Amazon Bedrock を通じて GPT-6 Astra を含む OpenAI フロンティアモデルへのアクセスをエンジニアリング・製品開発チーム全体に拡大した。Codex と GPT-5.6 系モデル (Sol、Terra、Luna) を活用した社内 AI アシスタントの実績の上に構築された今回の拡大では、バグ追跡やシステム設計などコーディング以外の領域でも成果が確認されており、開発チームの機能出荷数は前年比約 80% 増となっている。検索、不正防止、サポート、保険請求といったマーケットプレイス全体での AI 活用も進んでおり、旅行体験を 1 つのアプリに統合していく Airbnb の戦略を支える基盤となっている。
