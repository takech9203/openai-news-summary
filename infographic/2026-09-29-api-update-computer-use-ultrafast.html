API 更新

Agents API にコンピュータ操作機能を追加、GPT-6 Astra に Ultrafast モードが登場

📅 2026-09-29 | ソース: OpenAI API Changelog

エージェントのブラウザ操作と低レイテンシ推論、2 つの方向で API が進化 🚀

概要

🖥️

Agents API にコンピュータ操作 (computer use) 機能を追加

エージェントが OpenAI ホストのブラウザ内でウェブタスクを完了できるようになり、ブラウザ環境の構築・運用を OpenAI 側に任せられる。

🛡️

アクセス承認とサインインはアプリケーション側で制御

ウェブサイトへのアクセス承認と認証処理は開発者のアプリケーション側でハンドリングする設計。ガードレールを組み込みやすく、認証情報をモデルへの入力から分離できる。

⚡

GPT-6 Astra に Ultrafast モードが登場

Responses API で service_tier: "ultrafast" を指定すると、出力トークン間のレイテンシ (inter-token latency) を短縮できる。

🌎

Ultrafast はレート制限・データレジデンシーに注意

レート制限の対象で、グローバル処理と米国データレジデンシーのみ対応。EU などその他の地域推論レジデンシーはサポートされず、専用料金が適用される。

☀️

同日に GPT-6.1 Sol もリリース (別レポート参照)

複雑なコーディングとプロフェッショナルワーク向けの新モデル gpt-6.1-sol も同日発表。GPT-6 Astra より低コストで、ベータ版のマルチエージェント機能を備える。

Before / After: ブラウザ操作エージェントの構築

Before

  • スクリーンショット取得・アクション実行・環境維持の実行ループを開発者側で実装
  • 仮想マシンや Playwright / Selenium などのブラウザ自動化基盤を自前で構築・運用
  • インフラの維持コストが継続的に発生

After

  • OpenAI ホストのブラウザでエージェントがタスクを実行
  • ブラウザ環境の構築・運用が不要に
  • アクセス承認とサインインはアプリケーション側で制御し、安全性を確保

主要機能

🖥️ Agents API コンピュータ操作

エージェントが OpenAI ホストのブラウザ内でウェブタスクを完了。開発者が自前でブラウザ環境を構築・運用する必要がない。

"Agents can complete tasks in an OpenAI-hosted browser, with website access approvals and sign-in handled by your application."

🛡️ アプリケーション側の承認制御

エージェントがどのウェブサイトにアクセスできるかの承認 (approval) はアプリケーション側でハンドリング。意図しないサイトへのアクセスを防ぐガードレールを設けられる。

🔐 サインインの分離

認証が必要なサイトへのサインインもアプリケーション側で処理する設計。認証情報をエージェントのプロンプトに直接渡す必要がない。

⚡ GPT-6 Astra Ultrafast モード

Responses API で model: "gpt-6-astra" と service_tier: "ultrafast" を組み合わせて指定。最初のトークンだけでなく、ストリーミング中のトークン供給速度が向上し、長い応答でも体感速度が改善する。

☀️ GPT-6.1 Sol (同日リリース)

複雑なコーディングとプロフェッショナルワーク向けの新モデル。Responses API リクエスト内でのサブエージェントへの委任 (ベータ版マルチエージェント機能) に対応。詳細は別レポートを参照。

API 変更点

🆕 新パラメータ値: service_tier: "ultrafast"

service_tier は Responses API のリクエストパラメータで、リクエストの処理優先度・レイテンシ特性を制御する。今回のアップデートで GPT-6 Astra に対して "ultrafast" が指定可能になった。

項目 内容
パラメータ service_tier
新しい値 "ultrafast"
対象モデル gpt-6-astra
対象エンドポイント Responses API (v1/responses)
効果 出力トークン間レイテンシの短縮
データレジデンシー グローバル処理と米国のみ (EU などの地域推論レジデンシーは非対応)
料金 Ultrafast 専用料金 (料金ページ参照)

⚠️ 制約事項

⚠️
レート制限の対象: Ultrafast ティアはレート制限の対象となる。想定トラフィックに対するレート制限の確認が必要。
🌍
データレジデンシーの制限: グローバル処理 (global processing) と米国データレジデンシー (US data residency) のみ対応。Changelog 原文では "EU and other regional inference residency aren't supported." と案内されている。
💰
専用料金: Ultrafast ティア専用の料金が適用される。レイテンシ要件と予算に応じて標準ティアとの使い分けが必要。

コードサンプル

Python GPT-6 Astra を Ultrafast モードで呼び出す 
from openai import OpenAI

client = OpenAI()

# service_tier に "ultrafast" を指定して
# 出力トークン間のレイテンシを短縮する
stream = client.responses.create(
    model="gpt-6-astra",
    service_tier="ultrafast",
    input="リアルタイム対話アプリの応答を生成してください。",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="", flush=True)
JavaScript GPT-6 Astra を Ultrafast モードで呼び出す 
import OpenAI from "openai";

const client = new OpenAI();

const stream = await client.responses.create({
  model: "gpt-6-astra",
  service_tier: "ultrafast",
  input: "リアルタイム対話アプリの応答を生成してください。",
  stream: true,
});

for await (const event of stream) {
  if (event.type === "response.output_text.delta") {
    process.stdout.write(event.delta);
  }
}

ユースケース

🤖 ブラウザ操作を伴うエージェントの構築

フォーム入力、情報収集、ウェブ上の手続き代行など、ブラウザ操作を伴うエージェントを低コストで構築・運用できる。アクセス承認をアプリケーション側でハンドリングする設計のため、許可リストや人間による確認 (human-in-the-loop) を実装しやすく、認証情報もモデルへの入力から分離できる。

🎙️ 音声アシスタント・リアルタイム対話

service_tier: "ultrafast" により、音声対話やライブチャットなどトークン供給速度が体感品質に直結するユースケースで GPT-6 Astra を使いやすくなる。長い応答でもストリーミング中のトークン供給速度が向上し、体感速度が改善する。

⌨️ コーディング補完・リアルタイム UI

コーディング補完やリアルタイム UI など、応答の即時性が求められるアプリケーションに適する。ただし Ultrafast は専用料金が適用されるため、レイテンシ要件と予算に応じて標準ティアと使い分ける。

導入時のチェックポイント

  • Ultrafast はレート制限の対象となるため、想定トラフィックに対するレート制限の確認を行う
  • EU などの地域推論レジデンシーが必要なワークロードでは Ultrafast モードを利用できないため、コンプライアンス要件を事前に確認する
  • computer use を有効にする場合は、アクセス承認フローとサインイン処理の実装が前提となる
  • Ultrafast は専用料金が適用されるため、料金ページで具体的な金額を確認する

まとめ

2026 年 9 月 29 日の API Changelog では、エージェントと低レイテンシ推論という 2 つの方向でのアップデートが発表された。Agents API のコンピュータ操作機能は、OpenAI ホストのブラウザでエージェントがウェブタスクを完了できるようにし、アクセス承認とサインインをアプリケーション側で制御する設計により安全性と構築の容易さを両立している。GPT-6 Astra の Ultrafast モードは、service_tier: "ultrafast" を指定するだけで出力トークン間のレイテンシを短縮でき、リアルタイム性が求められるアプリケーションでの GPT-6 Astra 活用を後押しする。ただし Ultrafast は専用料金とレート制限の対象であり、EU などの地域推論レジデンシーには対応しない点に注意が必要である。
