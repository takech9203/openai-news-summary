Atlassian と OpenAI がパートナーシップを拡大 — エンタープライズナレッジをアクションへ

📅 2026-10-06 | OpenAI News

2023 年に始まった協業を拡大し、GPT-6 ファミリーのフロンティアモデルを Atlassian プラットフォームと Rovo 全体に展開。Teamwork Graph との統合で AI が企業の働き方を深く理解する。

概要 — 契約の主要ポイント

🚀

フロンティアモデルへの拡大アクセス

Atlassian は GPT-6 Astra や GPT-5.6 シリーズを含む最新の OpenAI フロンティアモデルへの拡大アクセスを獲得。OpenAI はモデルの能力・効率・価格性能比を継続的に向上させる。

🧠

Rovo と Teamwork Graph の統合

OpenAI モデルが Atlassian プラットフォームと Rovo 全体のエージェントを駆動。Teamwork Graph (人・プロジェクト・ドキュメント・意思決定をつなぐエンタープライズコンテキストレイヤー) が AI に企業コンテキストを提供する。

👩‍💻

Atlassian 社内での OpenAI 製品採用

Atlassian は Codex と ChatGPT Enterprise の社内採用を拡大。3,000 人以上の Atlassian 開発者がターミナル、IDE、コードレビューワークフローで Codex を使用している。

🔄

相互利用

OpenAI は引き続き Jira を利用して社内の重要なワークフローを管理。両社の相互採用が進んでいる。

🔗

OpenAI API による継続的な進化

OpenAI API を通じて、Atlassian はモデルの進化に合わせて新しい推論能力を Rovo に直接組み込める。顧客は既存のツール内でますます高性能な AI を利用できる。

Before / After — チームの働き方の変化

Before

  • Jira、Confluence、議論の情報が分散し、情報収集に時間がかかる
  • ツール間のコンテキスト切り替えが頻発
  • AI がプロジェクト固有のコンテキストを把握できない

After

  • Rovo が Teamwork Graph でチケット・ドキュメント・議論を接続し、評価と次のステップを提示
  • ChatGPT / Codex のプロンプトに Jira や Confluence の情報を直接取り込める
  • フロンティアモデルが企業コンテキストを理解した支援を提供

主要機能 — Atlassian 製品の枠を超えた連携

🔌 Atlassian・Teamwork Graph CLI プラグイン

ChatGPT と Codex を既存のワークフローに接続。適切な権限管理のもとで、AI がプロジェクト情報、ドキュメント、開発コンテキストにアクセスできる。

🧩 プラグイン拡張機能

Jira の作業アイテム、Confluence のコンテンツ、人物情報を ChatGPT と Codex のプロンプトに直接取り込める。ピン留めされた Atlassian Home では、割り当てられた作業、最近の Loom、プロジェクト、Bitbucket プルリクエストを表示。

💻 Codex と Teamwork Graph の連携

Teamwork Graph を活用した Atlassian プラグインにより、Codex ユーザーは関連する作業アイテムや技術ドキュメントにアクセスでき、ソフトウェアの作成・テスト・リリースを支援する。

🤖 Jira とのより深い統合 (今後)

チームが AI エージェントに作業を割り当て、進捗を追跡し、意思決定を記録し、結果をレビューしやすくすることを両社で模索中。

📊 DX による AI 効果測定 (今後)

Atlassian の開発者生産性・エンジニアリングパフォーマンス測定プラットフォーム DX と組み合わせ、人間による管理を維持しながら、開発速度、サイクルタイム、開発者体験に対する AI の影響を測定できる可能性。

ユースケース

📋 プロダクトマネージャー: ローンチ準備状況の即時把握

ローンチ準備中の PM が Rovo に「チームは予定通りか」と質問すると、Rovo は Teamwork Graph を活用して Jira チケット、Confluence ドキュメント、関連する議論を接続。エンジニアリング上のブロッカーの特定、未達マイルストーンの検出、注意が必要な意思決定の抽出を行い、OpenAI モデルが明確な評価と推奨される次のステップに変換する。

「チームは予定通り?」と Rovo に質問
→
Teamwork Graph が Jira / Confluence / 議論を接続
→
ブロッカー・未達マイルストーン・要注意の意思決定を検出
→
OpenAI モデルが評価と次のステップを提示

👨‍💻 開発者: プロジェクトコンテキストを活用したコーディング支援

Atlassian プラグインを通じて、Codex が Jira の作業アイテムや Confluence の技術ドキュメントを参照。コード作成・テスト・リリースの各段階で、プロジェクト固有のコンテキストを活用した支援が受けられる。

👔 エンジニアリングリーダー: AI エージェントの管理と効果測定 (将来展望)

Jira との深い統合により AI エージェントへのタスク割り当て・進捗追跡・結果レビューが可能に。DX との組み合わせで、人間による管理を維持しながら開発速度やサイクルタイムに対する AI の影響を定量評価できる可能性がある。

開発者への影響

  • 開発コンテキストへの AI アクセス: Codex が Jira の作業アイテムや Confluence の技術ドキュメントを参照でき、プロジェクト固有のコンテキストを活用した支援が受けられる
  • ワークフローの統合: ChatGPT と Codex を既存の Atlassian ワークフローに接続することで、ツール間のコンテキスト切り替えが減少
  • AI エージェントへの作業割り当て: Jira との深い統合が実現すれば、タスク割り当て・進捗追跡・結果レビューが標準的な開発プロセスの一部になる可能性
  • AI 効果の計測: DX との組み合わせにより、AI の影響を定量的に評価し、エンジニアリング組織における AI 導入の意思決定を支援
  • 権限管理: AI のデータアクセスは適切な権限 (permissions) に従うため、エンタープライズのセキュリティ要件を維持しながら利用できる

まとめ

Atlassian と OpenAI のパートナーシップ拡大は、GPT-6 Astra や GPT-5.6 シリーズといったフロンティアモデルを Rovo と Teamwork Graph に統合し、エンタープライズナレッジを実際のアクションに変換することを目指すもの。3,000 人以上の Atlassian 開発者による Codex 活用や、OpenAI 社内での Jira 利用など、両社の相互採用も進んでいる。今後は Jira への AI エージェント統合や DX による AI 効果測定など、人間の管理を維持しつつ AI をチームワークの中核に組み込む取り組みが期待される。
