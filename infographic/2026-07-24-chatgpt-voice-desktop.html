ChatGPT Voice がデスクトップアプリに対応

2026-07-24 新機能

概要

🎙

エージェント音声制御

ChatGPT Work および Codex と統合し、音声による指示で複数のエージェントを同時に制御可能

🖥

Computer Use による操作

Voice モードから Computer Use 機能を活用し、Web サイトやアプリケーションへのアクセスが可能

📸

Appshots (macOS)

画面上のコンテンツにアクセスし、alt テキストを含む情報を取得して文脈を踏まえた応答を実現

⚡

マルチステップコマンド

多段階にわたる複雑なコマンドを口述し、キーボードやマウスに触れずワークフローを実行

📱

iOS リモートアクセス

iOS アプリからリモートアクセスを通じて Codex を音声で操作、外出先から開発タスクを実行

スマートフォン版 vs デスクトップ版

Before: スマートフォン版

会話中心の設計

  • スムーズな会話に特化
  • 割り込み対応に優れる
  • アクション実行は非対応
  • エージェント連携なし
  • Computer Use 非対応
After: デスクトップ版

アクション指向の設計

  • マルチステップワークフロー対応
  • Codex、ChatGPT Work と統合
  • Web サイト・アプリ操作可能
  • Appshots による画面認識
  • iOS からのリモートアクセス

主な機能

🎤

Agent Voice Control

音声で「プルリクエストを作って、バグの根本原因を見つけて」と指示するだけで、複数タスクが並行実行される

🖱

Computer Use

音声指示で ChatGPT が画面上の操作を代行。Web サイトを開いて情報を確認するなどのタスクを実行

👁

Appshots (macOS)

画面上のコンテンツにアクセスし、コードエディタの内容認識やエラーメッセージの読み取りが可能

🔗

Multi-step Commands

多段階の複雑なコマンドを口述。確認が必要な場面ではユーザーに音声で問いかけてタスクを完遂

🌐

iOS Remote Access

外出先から iOS アプリ経由でデスクトップ上の Codex に音声指示を出し、開発タスクを進行

開発者への影響

🙌 ハンズフリー開発

コードレビュー、プルリクエスト作成、バグ調査を音声指示で実行可能。手を使えない状況でも開発作業を継続できる

🔀 マルチタスキングの強化

コーディング中に音声でエージェントに別タスクを指示し、並行作業を実現。Codex への音声連携でコード生成やリファクタリングを依頼

♿ アクセシビリティの向上

キーボード操作が困難なユーザーに新たな開発手段を提供。画面の alt テキスト読み取りにより視覚的情報へのアクセスも改善

競合動向

同時期に Anthropic も Claude の音声モードをアップデートし、Opus、Sonnet、Haiku の各モデルを活用して Gmail、Calendar、Slack、Notion、Canva などのアプリケーション内でタスクを完了する機能を提供している。音声による AI エージェント制御は、主要 AI 企業間で競争が激化している領域である。
