OpenAI モデルによるチップ設計の進化

Jalapeño シリコンと RISC-V コア最適化の成果 — AI 支援チップ設計が実シリコンで実証される段階へ

2026-11-18 | OpenAI Research

概要

🌶️

Jalapeño シリコンで実証済みの面積削減

自社開発の推論用カスタムチップ「Jalapeño」の演算ブロックをモデルが最適化。ベクトルユニットで約 13%、行列ユニットで約 10% の標準セル面積削減を実シリコンのブリングアップで実証した。

⚡

AMD GPU IP で最大 14% の PPA 改善

SystemVerilog RTL の書き換えにより、人手で高度に最適化済みのベースラインに対して最大 14% の PPA (Power, Performance, Area) 改善を達成。「約 1 年分の進歩を 5 か月未満で達成」と表現されている。

📊

RISC-V コアによる体系的ベンチマーク

オープンソースの 32 ビット RISC-V コア (PicoRV32、Ibex) を題材に、合計 9,881 回のスコア付き実行でモデル能力を定量評価した。

📐

仕様書からのゼロベース設計でも高スコア

最新モデル GPT-6.2 Astra は既存 RTL の最適化だけでなく、仕様書からのゼロベース設計でも高いスコアを記録。評価対象の 5 モデルすべてが、仕様からの設計で最適化タスクを上回った。

🤝

Synopsys 提携で「GPT-Synopsys」を訓練中

EDA ツールを専門家のように使いこなす新モデル「GPT-Synopsys」の訓練が進行中。AI 支援チップ設計は研究段階から産業実装へ移行しつつある。

主要な成果

🌶️ Jalapeño 演算ブロックの最適化

2025 年初頭に o3-mini で開始し「非自明な PPA 改善」を確認。ベクトルユニットでは浮動小数点加算器・乗算器、変換関数、リダクションロジック、特殊関数ユニットの面積を削減。代替ロジックの探索やパイプラインステージ分割の変更をモデルが提案した。

🔢 行列ユニットの再設計

ある乗算器の再設計では、合成時のセル面積を約 15% 削減しつつ、レイテンシを 2 クロックサイクルから 1 サイクルに短縮。別の加算器では 2 サイクルのレイテンシを維持したままセル面積を約 15% 削減した。

⚡ AMD GPU/CPU IP の PPA 改善

フラッグシップ GPU IP で最大 14% の PPA 改善。AMD は一部の変更を製造向け設計に採用し、その他も量産設計ファイルに組み込んだ。次世代フラッグシップ CPU の主要ブロックでも 1 桁パーセントの改善を検証。モデルは「熟練マイクロアーキテクトのレベル」で推論した。

📊 RISC-V コアの体系的評価

FPGA 向けのコンパクトな PicoRV32 と、OpenTitan で採用される組み込みプロセッサ Ibex の 2 種類を題材に、スループット (1 秒あたりの命令実行数) 向上タスクで 9,881 回のスコア付き実行を実施した。

🤝 Synopsys 連携 — GPT-Synopsys

検証と PPA トレードオフ評価には Synopsys のツールを使用。さらに提携により、EDA ツールを専門家のように操作する専用モデル「GPT-Synopsys」を訓練中。GPU・CPU 設計でのさらなる PPA 改善を目指す。

仕様書からのゼロベース設計

文書化された要件と接続テンプレートのみを与え、データフローやパイプラインステージングをモデル自身に選択させるタスクも評価された。評価対象の 5 モデルすべてが、既存 RTL の最適化よりも仕様からの設計で高いスコアを記録 (両コア共通)。GPT-6.2 Astra は PicoRV32 で平均 0.7、Ibex で約 0.75 のスコアを達成した。

注意点: 仕様ベースの設計はパフォーマンスカウンタや追加命令などの機能を省略する可能性があり、それがスコアの高さの一因である点に OpenAI 自身が言及している。より厳しい面積制限や物理合成後のタイミング検証を導入することで、評価の現実性が向上するとしている。

開発者への影響

🛠️ ハードウェア設計者

RTL 最適化や仕様からの設計において、AI モデルが熟練マイクロアーキテクトに匹敵する提案を行えることが実シリコンで実証された。設計サイクルの大幅な短縮 (1 年分の進歩を 5 か月未満で達成) が期待できる。

🔧 EDA エコシステム

Synopsys との提携による「GPT-Synopsys」の登場で、EDA ツールを AI が直接操作する設計フローが現実味を帯びる。

🌐 RISC-V コミュニティ

PicoRV32 や Ibex といったオープンソースコアが AI 設計能力のベンチマークとして採用されており、オープンな評価基盤の重要性が増している。

🔬 AI 研究者

トークン予算の増加に伴いスコアが伸び続ける傾向が示されており、推論時スケーリングがハードウェア設計タスクでも有効であることを示唆している。

まとめ

OpenAI は、自社モデルがチップ設計の最前線で実用的な成果を上げていることを、実シリコン (Jalapeño)、産業パートナーシップ (AMD)、体系的ベンチマーク (RISC-V コア) の 3 つの証拠で示した。Jalapeño ではベクトルユニットで約 13%、行列ユニットで約 10% の面積削減を達成し、AMD の GPU IP では最大 14% の PPA 改善を量産設計に反映した。GPT-6.2 Astra は既存 RTL の最適化と仕様からのゼロベース設計の両方で先行モデルを上回り、特に後者では全モデルが最適化タスクを超えるスコアを記録した。今後は Synopsys と共同で EDA ツールを使いこなす専用モデル「GPT-Synopsys」を訓練し、GPU・CPU 設計でのさらなる PPA 改善を目指すとしており、AI 支援チップ設計は研究段階から産業実装へと移行しつつある。
