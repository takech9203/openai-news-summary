新機能 API 更新

🎙️ GPT-Live-1 が API で提供開始

全二重 (full-duplex) の音声会話で、より自然な音声体験の構築が可能に

📅 2026-09-10 | OpenAI News / API Changelog

概要

🔊

全二重の音声会話モデルが一般提供 (GA) 開始

発話と聴取を同時に行えるため、割り込みや相槌を含む、人間同士の会話に近い自然なやり取りを実現できる

🎯

指示追従 (instruction following) の強化

トーンやスピードの指定、業務フローに沿った応対をより正確に反映し、一貫したペルソナの維持が容易に

🎨

カスタム音声とテレフォニーをサポート

ブランド独自の音声体験の構築に加え、SIP 経由で既存の電話システムに AI 音声エージェントを組み込める

💰

シンプルな時間ベース課金

音声セッション 1 分あたり $0.05、秒単位課金。通話時間からコストを直接見積もれる

Before / After: 音声対話の進化

Before: ターン制の音声対話

  • 発話の切れ目を待ってから応答
  • 応答待ちの不自然な間 (ま) が発生
  • ユーザーの割り込みに反応しにくい

After: GPT-Live-1 (全二重)

  • 発話と聴取を同時に実行
  • 割り込み (barge-in) に即座に反応
  • 文脈に応じた自然なターンテイキング

主要機能

🔁 全二重 (Full-Duplex) 音声会話

GPT-Live-1 最大の特徴。会話のテンポが人間同士の対話に近づく。

  • 同時発話と聴取: 話している間もユーザーの音声を聞き続ける
  • 自然なターンテイキング: 文脈に応じて話し始め・話し終わりを判断
  • 低レイテンシな応答で不自然な間が減少

📋 指示追従の強化

システムプロンプトや開発者の指示への追従性が向上。

  • 話し方のトーン・スピード・応対スタイルを正確に反映
  • 本人確認手順やエスカレーション条件など業務フローを確実に実行
  • 音声エージェントとして一貫したペルソナを維持

🎨 カスタム音声のサポート

プリセット音声に加えて、独自の音声体験を構築可能。

  • ブランドやサービスに合わせた音声を利用
  • 製品の世界観に統一感のある音声インターフェースを提供

☎️ テレフォニー (電話) サポート

電話回線経由の音声対話に対応。

  • コールセンターや電話応対の自動化ユースケースに対応
  • SIP などの電話インフラと接続し、既存の電話システムに組み込み可能

技術詳細

GPT-Live-1 は Realtime API を通じて利用でき、3 つの接続方式に対応する。

🌐 WebRTC (ブラウザ) 🔌 WebSocket (サーバー) ☎️ SIP (テレフォニー)

コードサンプル

Python Realtime API で GPT-Live-1 セッションを開始する例 (WebSocket) 
# Realtime API で GPT-Live-1 セッションを開始する例 (WebSocket)
import json
import websocket

url = "wss://api.openai.com/v1/realtime?model=gpt-live-1"
headers = [
    "Authorization: Bearer " + OPENAI_API_KEY,
]

ws = websocket.create_connection(url, header=headers)

# セッション設定: 指示とカスタム音声を指定
ws.send(json.dumps({
    "type": "session.update",
    "session": {
        "instructions": "あなたは丁寧なカスタマーサポート担当です。",
        "voice": "custom-brand-voice",
        "turn_detection": {"type": "semantic_vad"},
    }
}))
JavaScript ブラウザから WebRTC で接続する例 
// ブラウザから WebRTC で接続する例
const pc = new RTCPeerConnection();
const dc = pc.createDataChannel("oai-events");

const offer = await pc.createOffer();
await pc.setLocalDescription(offer);

const response = await fetch(
  "https://api.openai.com/v1/realtime?model=gpt-live-1",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${EPHEMERAL_KEY}`,
      "Content-Type": "application/sdp",
    },
    body: offer.sdp,
  }
);

注: 上記は Realtime API の一般的な利用パターンに基づくサンプルであり、正確なパラメータは 公式ドキュメント を参照のこと。

ユースケース / 開発者への影響

📞 コールセンター・電話応対の自動化

テレフォニーサポートにより、コールセンターや予約受付などの電話ベースのユースケースに AI 音声エージェントを直接組み込める。指示追従の強化で、本人確認やエスカレーションなどの業務フローも確実に実行できる。

🗣️ 自然な音声 UX を持つ音声アシスタント

全二重対応により、割り込みや相槌を含む自然な会話体験を実装できる。従来のターン制音声対話で課題だった「応答待ちの不自然な間」が解消され、音声 UX が質的に向上する。

🏷️ ブランド体験の統一とスムーズな移行

カスタム音声により、サービス独自の音声アイデンティティを構築できる。すでに Realtime API で音声機能を実装している場合、モデル指定の変更を中心に GPT-Live-1 の恩恵を受けられる可能性が高い。

まとめ

GPT-Live-1 の一般提供開始により、API 経由で全二重の自然な音声会話を構築できるようになった。指示追従の強化、カスタム音声、テレフォニーサポートという 3 つの柱により、カスタマーサポート・電話応対・音声アシスタントといった実務ユースケースへの適用が現実的になっている。1 分 $0.05 (秒単位課金) というシンプルな料金体系も、音声アプリケーションの商用展開を後押しする。
