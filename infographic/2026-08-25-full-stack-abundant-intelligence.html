潤沢なインテリジェンスを支えるフルスタック

OpenAI CFO Sarah Friar 氏が語るコンピュート戦略 — チップからデバイスまでを 1 つの統合システムとして改善する「複利的優位性」

📅 2026-08-25 | OpenAI News

概要

🏗️

フルスタックの統合システム

データセンター、チップ、フロンティアモデル、開発者プラットフォーム、製品、AI ネイティブデバイスを 1 つのシステムと捉え、各レイヤーの改善が相互に強化し合う戦略を CFO が解説

🌶️

自社製推論チップ「Jalapeño」初の実測結果

公開ベンチマーク InferenceX (GPT-OSS 120B) で、商用システムを上回るキロワットあたりピークスループットと低いトークンレイテンシを達成。次世代チップも開発中

⚖️

Build for breadth, own for leverage

Microsoft / NVIDIA を基盤に AWS、AMD、Broadcom、Cerebras、CoreWeave、Oracle などを含む多様なポートフォリオで「パレートフロンティア」上の最適配置を追求

📉

効率を経済価値へ転換

GPT-5.6 Sol は 54% 少ない出力トークンで Artificial Analysis Coding Agent Index の過去最高スコアを達成。「有用なインテリジェンス / ドル」を最適化指標に

🔁

複利的優位性 (Compounding Advantage)

より良い技術 → より良い経済性 → 次の進歩への投資という複利ループが OpenAI の成長エンジン。効率向上分はユーザーに還元される

戦略の柱

🔄 相互強化のフィードバックループ

優れたソフトウェアがハードウェアの生産性を高め、自社ワークロード向けハードウェアが速度と効率を改善。高性能モデルが良い製品を生み、需要・利用・学習のシグナルがシステムに還流する

🌶️ Jalapeño: ファーストパーティの選択肢

モデル、サービングソフトウェア、チップ、メモリ、ネットワークを一体開発。DeepSeek R1 や Kimi K2 でも強い性能を示し、従来最速の TBT (Time Between Tokens) に対してもリードを拡大

📊 パレートフロンティアへの残留

学習・大量推論・常時稼働エージェントなどワークロードごとに異なる要件に対し、能力・速度・信頼性・効率・コストの最適な組み合わせを常に追求。ドルあたり性能が最も高い先へ需要を振り向ける

🏭 Project Camellia (ジョージア州)

顧客ワークロードに合わせた施設設計に加え、雇用創出、地元企業支援、閉ループシステムによる水資源の節約、年次の独立公開監査など地域コミットメントを示すデータセンター事例

💹 ジェボンズのパラドックス

効率の向上はより多くの用途を経済的に成立させ消費を拡大。全顧客へのカスタマイズ分析、全契約書レビュー、リアルタイム財務シナリオ実行などが経済的に実用となる

コンピュートポートフォリオ: Microsoft のコンピュートと NVIDIA のチップを成長の基盤とし、クラウドインフラ、アクセラレーテッドコンピューティング、低レイテンシ推論、データセンター開発、エネルギー供給の各分野で強みを持つパートナーを組み合わせる。

ポートフォリオ管理の方針

  • 適材適所: 能力が最重要の場面ではプレミアムなシステムを使い、規模とコストが重要な場面では効率を最適化する
  • 信頼できる選択肢の維持: プロバイダー、ハードウェア、デプロイモデル間で選択肢を維持し、ドルあたり性能が最も高い先へ需要を振り向ける
  • 価格規律: 市場環境の変化に応じて価格規律を維持し、より強い技術が登場すればフロンティアとともに移行する
  • パートナー協業と自社構築の使い分け: エコシステムが速度を上げる場面ではパートナーと組み、共同設計が大きな優位を生む場面では自社構築する

開発者への影響・ユースケース

💰 推論コストの継続的な低下と供給の安定性

Jalapeño などの自社シリコンとマルチベンダー戦略により、効率向上分が API 価格やサービス品質として還元される方針が明示された。供給基盤の多様化により、ワークロードに応じた最適配置でキャパシティと価格規律の維持が期待できる。

🤖 トークン効率によるエージェントワークフローの改善

GPT-5.6 Sol が 54% 少ない出力トークンで最高スコアを達成したように「有用なインテリジェンス / ドル」が最適化指標となっており、より速い結果、リトライの減少、より長いワークフローを完遂できるエージェント、成功する作業あたりの総コスト低減に直結する。

🌐 オープンモデルとの互換性と新たな経済活動

Jalapeño のベンチマークに GPT-OSS 120B、DeepSeek R1、Kimi K2 が使われ、性能向上が特定モデルに限定されないことを実証。効率向上により、全顧客へのカスタマイズ分析、全契約書のレビュー、リアルタイムの財務シナリオ実行などが経済的に実用となる。
