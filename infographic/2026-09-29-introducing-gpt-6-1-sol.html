GPT-6.1 Sol 発表

Astra 級の知能を 1/5 のコストで提供する新モデル gpt-6.1-sol

📅 2026-09-29 | OpenAI News (Product)

概要

OpenAI は 2026 年 9 月 29 日、新モデル GPT-6.1 Sol を発表。フラッグシップの GPT-6 Astra に迫る知能 (near-Astra intelligence) を、1/5 の API 価格で利用できるコスト効率重視のモデルです。

🧠

Astra 級の知能を低価格で

コーディング、コンピュータ操作、プロフェッショナル業務で GPT-6 Astra に迫る知能を実現しながら、標準 API 価格を Astra の 1/5 に抑制

💰

入力 $2 / 出力 $10 per 100 万トークン

標準価格は 100 万トークンあたり入力 $2、出力 $10。複雑なタスクを低コストで処理でき、大規模ワークロードでも採用しやすい

🤝

マルチエージェント機能をベータ提供

複数のエージェントを連携させるワークフローを構築可能。低価格な特性と組み合わせ、多数のエージェントを並列稼働させてもコストを抑えやすい

🔌

既存 API からすぐに利用可能

モデル ID gpt-6.1-sol を指定するだけで、既存の API (Responses API) からそのまま利用できる

モデル仕様

モデル ID gpt-6.1-sol
入力価格 $2 / 100 万トークン
出力価格 $10 / 100 万トークン
対 Astra 価格比 入力・出力ともに 1/5
主な用途 コーディング、コンピュータ操作、プロフェッショナル業務
マルチエージェント機能 ベータ提供

主要機能

💻 コーディング

複雑なコーディングタスクに対応。コード生成、リファクタリング、デバッグなどの開発ワークフローを低コストで自動化できます。

🖥️ コンピュータ操作

画面操作を伴うエージェントタスク (computer use) に対応。ブラウザ操作や業務アプリケーションの自動操作などを実現します。

📊 プロフェッショナル業務

文書作成、分析、レビューなどの専門的なナレッジワークを高い知能で処理。Astra 級の品質を低コストで利用できます。

🤖 マルチエージェント Beta

複数のエージェントを連携させるワークフローを構築可能。低価格モデルとの組み合わせで並列エージェント構成のコストを抑制します。

技術詳細: コードサンプル

Python GPT-6.1 Sol でコーディングタスクを実行 
from openai import OpenAI

client = OpenAI()

# GPT-6.1 Sol でコーディングタスクを実行
response = client.responses.create(
    model="gpt-6.1-sol",
    input=[
        {
            "role": "user",
            "content": "Python で CSV ファイルを読み込み、"
                       "列ごとの統計情報を出力する関数を書いてください。",
        }
    ],
)

print(response.output_text)

ユースケース

💻 開発ワークフローの低コスト自動化

コード生成、リファクタリング、デバッグなどの複雑なコーディングタスクを Astra 級の知能で処理。大規模なバッチ処理でもコスト構造を大きく改善できます。

🖥️ 画面操作を伴うエージェントタスク

ブラウザ操作や業務アプリケーションの自動操作など、コンピュータ操作 (computer use) を活用したエージェントを低コストで運用できます。

🤖 マルチエージェントワークフローの構築

ベータ提供のマルチエージェント機能により、複数エージェントの連携ワークフローを構築。多数のエージェントを並列に動かす構成でもコストを抑えやすくなります。

開発者への影響

  • 💸コスト削減: Astra 級の知能を必要とするワークロードを 1/5 の価格で運用でき、大規模なバッチ処理やエージェント運用のコスト構造を大きく改善できる
  • 🧩エージェント構築の選択肢拡大: コーディングやコンピュータ操作に強く、マルチエージェント機能 (ベータ) も利用できるため、エージェントワークフローの標準モデル候補になる
  • 🔄モデル選定の見直し: これまで価格を理由に下位モデルを選んでいたユースケースで、GPT-6.1 Sol への移行を検討する価値がある
  • ⚠️ベータ機能への注意: マルチエージェント機能はベータ提供のため、本番導入前に仕様変更の可能性を考慮する必要がある

まとめ

GPT-6.1 Sol は、GPT-6 Astra に迫る知能を 1/5 の価格 (入力 $2 / 出力 $10 per 100 万トークン) で提供する新モデル。コーディング、コンピュータ操作、プロフェッショナル業務が主なターゲットで、マルチエージェント機能もベータ提供。高い知能と低コストの両立により、大規模ワークロードやエージェント構築におけるモデル選定の有力な選択肢となります。
