ChatGPT の GPT-5.6 Sol を改善、無料ユーザーにも GPT-5.6 Luna を拡大

より焦点を絞った回答と信頼できる事実性、そして無制限テキストチャットへ

📅 2026-08-06 | ソース: OpenAI News

概要

OpenAI は ChatGPT の日常的な会話体験を改善するアップデートを発表。毎週 10 億人が利用する ChatGPT の利用実態に合わせたチューニングと、最新モデルへのアクセス拡大を同時に実現する。

🎯

GPT-5.6 Sol の更新 (Plus/Pro)

事実に関する信頼性の向上と、より焦点を絞った回答を実現。役に立たない余分な詳細を回避する設計に。

🎚️

思考量スライダーの導入

Plus および Pro ユーザーは、回答にどの程度の思考を費やすかを新しいスライダーで選択可能に。

🌙

GPT-5.6 Luna が無料ユーザーのデフォルトに

Free および Go ユーザーのデフォルトモデルが GPT-5.6 Luna に更新され、テキストチャットが無制限に利用可能に。

💭

Think ボタンで高度な推論へ

より深い思考が必要な質問に対して、無料ユーザーも新しい Think ボタンで高度な推論機能にアクセス可能に。

主な内容

🎯 より焦点を絞った回答

より直接的な回答、引き締まったフォーマット、余分な詳細の回避を目的として設計。

  • 簡単な質問: 必要なコンテキストを含む直接的な回答
  • 複雑な作業 (複数ステップの計画、リサーチ、執筆): 主要な推奨事項を明確に保ちつつ充実した回答
  • 質問に応じて詳細レベルを適応、不要なフォーマットを回避
  • 同意が有益でない場合には役立つ訂正を提示

✅ より信頼できる事実性

日付、数値、情報源、ルール、前提条件に依存する回答で、検索で見つけた情報源をより適切に活用し間違いを削減。金融、医療、法律関連プロンプトの内部評価で、事実誤認を含む回答が GPT-5.5 Instant 比で大幅に減少。

🔄 Instant と Thinking の一貫した体験

Instant 体験と Thinking 体験がより近づき、トーンと挙動の一貫性が向上。高い思考レベルに移行しても別モデルへの切り替えではなく、同じモデルが追加の時間をかけているように感じられる設計。スライダーは Web、モバイル、デスクトップで利用可能。

🆓 無料ユーザーへのアクセス拡大

  • GPT-5.6 Luna がデフォルトに: 今週中に Free/Go ユーザーに適用
  • 無制限テキストチャット: 来週からレート制限なし (不正利用防止ガードレール対象)
  • Think ボタン: 難しい質問にじっくり考える時間を付与
  • 制限の継続: ファイルアップロード、画像、その他ツールは引き続き制限

開発者への影響

🔌 API への直接的な影響はなし

今回のアップデートは ChatGPT の Chat 体験に限定されており、Work および Codex を支える GPT-5.6 Sol は変更されないため、API 経由の利用や既存のワークフローへの影響はない。

📈 事実性の改善傾向

金融、医療、法律分野での事実誤認が GPT-5.5 Instant 比で 62-68% 減少しており、事実性を重視したモデルチューニングの方向性は、今後の API 向けモデルにも波及する可能性がある。

🎚️ 推論量の可変制御という UX パターン

スライダーや Think ボタンによる推論量の制御は、API における reasoning effort パラメータと同様の考え方であり、エンドユーザー向けアプリケーション設計の参考になる。

🌍 無料ユーザー層の拡大

無制限テキストチャットにより ChatGPT の利用者層がさらに拡大し、AI アシスタントの利用が一般化することで、開発者が構築するサービスへのユーザー期待値も変化する可能性がある。

まとめ

OpenAI は ChatGPT の GPT-5.6 Sol を更新し、より焦点を絞った回答と事実誤認の最大 68% 削減 (対 GPT-5.5 Instant) を実現。Plus および Pro ユーザーは新しいスライダーで思考量を調整でき、Instant と Thinking の体験が一貫したものに。無料ユーザーには GPT-5.6 Luna がデフォルトモデルとして提供され、無制限のテキストチャットと Think ボタンによる高度な推論へのアクセスが拡大。18 歳未満のユーザー向けの安全対策も強化され、「より多くの人により多くの知能を」という OpenAI のミッションを体現するアップデートである。なお、今回の変更は ChatGPT の Chat 体験に限定され、Work および Codex 向けのモデルは変更されない。
