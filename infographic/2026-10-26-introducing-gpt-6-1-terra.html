新モデル GPT-6.1 Terra を発表

OpenAI は 2026 年 10 月 26 日、「高速かつ高性能なコンピュータ操作 (computer use) をすべての人に届ける」モデルとして GPT-6.1 Terra を発表した。

⚡

高速・効率的な設計

速度と効率を重視した設計で、コンピュータ操作を広いユーザー層に提供することを目的としている。

🧩

3 つの能力を搭載

視覚的推論 (visual reasoning)、コンピュータ操作 (computer use)、自然な文章生成 (natural writing) に対応したモデルとして提供される。

🔌

発表と同時に API リリース

API Changelog (2026-10-26) にて同日付でリリースが告知されており、発表と同時に API 経由で利用可能になった。

主な機能

👁️ 視覚的推論

画面などの視覚情報を理解・推論する能力を備える (Visual Reasoning)。

🖥️ コンピュータ操作

GUI 操作などのコンピュータ操作タスクに対応する (Computer Use)。

✍️ 自然な文章生成

自然な文章を書く能力が特徴として挙げられている (Natural Writing)。

⚡ 高速・効率的

速度と効率を重視した設計で、コンピュータ操作を広いユーザー層に提供することを目指す。

ユースケース / 開発者への影響

🤖 コンピュータ操作エージェントの構築

高速・効率的なモデルとして提供されるため、画面操作を伴うエージェント型アプリケーションを、より広いユースケースで実用化しやすくなる可能性がある。

🔍 視覚的推論を伴うワークフロー

スクリーンショットや UI の理解を必要とするタスク (テスト自動化、業務自動化など) への適用が考えられる。

📝 文章生成用途との両立

コンピュータ操作に加えて自然な文章生成も特徴とされており、操作と文書作成を組み合わせたワークフローへの活用が期待できる。

📋 仕様確認の必要性

モデル ID や価格などの詳細は未確認のため、導入前に公式ドキュメントでの確認が必要。

まとめ

GPT-6.1 Terra は、2026 年 10 月 26 日に発表・API リリースされた高速・効率的なモデルで、視覚的推論、コンピュータ操作、自然な文章生成を特徴とする。「コンピュータ操作をすべての人に」という位置づけから、エージェント型のコンピュータ操作ユースケースの普及を狙ったモデルと考えられる。詳細仕様は公式ドキュメントでの確認が推奨される。
