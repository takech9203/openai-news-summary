API 更新 / 料金

ChatGPT Pro および Business の対象加入者向けに
月額最大 $500 の無料 API クレジット特典を開始

📅 発表日: 2026-10-28

📰 ソース: OpenAI API Changelog

概要

OpenAI は 2026 年 10 月 28 日、対象となる ChatGPT Pro および Business 加入者に対し、サブスクリプション特典として月額最大 $500 の無料 API クレジットを提供する機能を発表した。ChatGPT のサブスクリプションと API プラットフォームの利用をつなぐ特典であり、ChatGPT の有料加入者が追加コストなしで API 開発を試せるようになる点で、開発者にとって重要なアップデートとなる。

開発者への影響 / ユースケース

💸 API 利用コストの削減

ChatGPT Pro / Business 加入者は、月額最大 $500 分まで追加コストなしで API を利用できるようになる。

🛠️ プロトタイピングの促進

個人開発者やチームが、API を使った開発・検証を無料クレジットの範囲で開始しやすくなる。

✅ 手続きの確認が必要

特典を受けるには、自身が所有する API 組織をリンクする手続きが必要となる。適格基準の詳細は公式ガイドで確認する必要がある。

まとめ

OpenAI は ChatGPT Pro および Business の対象加入者に対し、月額最大 $500 の無料 API クレジットをサブスクリプション特典として提供開始した。特典は ChatGPT または API Platform から有効化し、自身が所有する API 組織をリンクすることで利用できる。プラン別のクレジット額や詳細な適格基準は公式ガイドに記載されているため、利用前に確認が必要である。
