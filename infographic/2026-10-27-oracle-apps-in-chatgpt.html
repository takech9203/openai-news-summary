OpenAI が Oracle とのパートナーシップを拡大、Oracle アプリを ChatGPT に統合へ

エージェント対応エンタープライズの実現に向けた協業強化

📅 2026-10-27 | ソース: OpenAI News

概要

🤝

パートナーシップの拡大を発表

OpenAI と Oracle は、Oracle のビジネスアプリケーションとデータを ChatGPT に統合するとともに、OpenAI のモデルと製品で Oracle の新しい製品・サービスを強化するため、パートナーシップを拡大すると発表した。

🏢

企業の AI 活用を支援

企業が AI を活用して中核業務の運営、より良いアプリケーションの構築、セキュリティの強化を実現できるよう支援することを両社は目指す。

🧩

Oracle AI Workspace を開発中

Oracle アプリケーションおよびデータとの統合を ChatGPT 内で実現する Oracle AI Workspace を Oracle が開発している。

🛠️

OpenAI モデル活用の新製品を発表

AI Security Mesh、AI SMB Bundle、App Composer という OpenAI のモデルとツールを活用した 3 つの新サービス・アップデートを Oracle が発表した。

🛒

Oracle Marketplace で OpenAI 製品を購入可能に

米国の Oracle 顧客は、既存の調達プロセスと Oracle Universal Credits を使用して、Oracle Marketplace 経由で OpenAI API、Codex、ChatGPT Work を購入できる。

エージェント対応エンタープライズのビジョン

OpenAI と Oracle は、人と AI エージェントが 1 つの接続された環境でビジネスアプリケーションを横断して働く「エージェント対応エンタープライズ (agent-ready enterprise)」のビジョンを共有している。

🔧 よりシンプルな管理

Oracle ソフトウェアをより発見・利用・管理しやすくすることが両社の目標。

🔑 統一されたサインイン

統一されたサインインにより、アプリケーション横断の利用体験を簡素化する。

🛡️ 権限と承認に基づくアクセス制御

各組織の権限と承認に基づくアクセス制御を前提に、安全な AI 活用を実現する。

ChatGPT 内での Oracle との連携 (Oracle AI Workspace)

Oracle は、Oracle アプリケーションおよびデータとの統合を通じてこのビジョンを ChatGPT 内で実現する Oracle AI Workspace を開発している。

💬 記述するだけで完了

ユーザーが達成したいことを記述するだけで、適切な情報を見つけ、承認済みのビジネスワークフローを 1 か所で完了できるようにすることが目標。

🔗 アプリ横断の情報統合

財務、調達、計画の各アプリケーションからの情報を統合し、組織の権限と承認の範囲内でより多くの従業員が Oracle ソフトウェアを活用できるようにする。

💡 利用シーンの例

財務チームの新メンバーが ChatGPT を使ってコストを調査し、購買の意思決定を理解し、月次決算までに残っている作業を特定する、といった利用シーンが示されている。

OpenAI のモデルを活用した Oracle の新製品

Oracle AI Workspace に加え、Oracle は OpenAI のモデルとツールを活用した以下のアップデートと新サービスを発表している。

セキュリティ

🛡️ Oracle AI Security Mesh

OpenAI のサイバーモデルを使用して、アプリケーションとインフラストラクチャの脆弱性の発見と修正を支援する。Oracle がテストインフラを管理し、顧客が認可された範囲内で安全にこれらの機能を活用できるようにする。

中小企業向け

📦 Oracle AI SMB Bundle

ChatGPT Business と Codex を Oracle アプリケーションおよび継続的な Oracle Cloud Infrastructure クレジットと組み合わせ、中小企業の製品開発と業務管理を支援する。

アプリ構築

🧱 Oracle App Composer

Codex などの AI ツールを使ったアプリ構築、承認済みの Oracle データ・ワークフローへの接続、組織内での共有を支援する。Oracle が Oracle Cloud Infrastructure 上のデプロイを管理し、企業の権限とアクセス制御が組み込まれる。

Oracle Marketplace 経由での OpenAI 製品の購入

対象 米国の Oracle 顧客
購入チャネル Oracle Marketplace
支払い手段 既存の調達プロセスと対象となる Oracle Universal Credits
購入可能な OpenAI 製品 OpenAI API、Codex、ChatGPT Work

開発者・企業への影響

📊 ChatGPT 上での Oracle アプリ横断ワークフロー

Oracle アプリケーション (財務、調達、計画など) の情報を ChatGPT 上で横断的に参照し、承認済みワークフローを完了できるようになる見込み。

🧱 App Composer による権限管理付きアプリ開発

Oracle App Composer により、Codex などの AI ツールで構築したアプリを承認済みの Oracle データ・ワークフローに接続し、OCI 上で権限管理付きでデプロイ・共有できる。

🏪 中小企業向けのまとめて導入

中小企業は Oracle AI SMB Bundle を通じて ChatGPT Business、Codex、Oracle アプリケーション、OCI クレジットをまとめて利用できる。

🛒 既存調達プロセスでの OpenAI 製品購入

米国の Oracle 顧客は、既存の調達プロセスと Oracle Universal Credits を使い、Oracle Marketplace から OpenAI API、Codex、ChatGPT Work を購入できる。

まとめ

OpenAI と Oracle のパートナーシップ拡大により、Oracle アプリケーションとデータが ChatGPT に統合され (Oracle AI Workspace)、OpenAI のモデルを活用した Oracle の新製品 (AI Security Mesh、AI SMB Bundle、App Composer) が展開される。権限と承認に基づくガバナンスを前提に、人と AI エージェントが業務アプリケーションを横断して協働する「エージェント対応エンタープライズ」の実現を両社は目指している。米国では Oracle Marketplace 経由で OpenAI 製品の購入も可能になる。
