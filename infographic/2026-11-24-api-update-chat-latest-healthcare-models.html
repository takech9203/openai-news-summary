🩺 API Update: chat-latest スナップショット更新とヘルスケアモデル構成の公開

ChatGPT 最新モデルのスナップショット切り替えと、臨床質問に特化した 4 つのヘルスケアモデル構成が Responses API に登場

📅 2026-11-24 | ソース: OpenAI API Changelog

概要

🔄

chat-latest スナップショットの更新 Update

ChatGPT (Plus / Pro / Business / Enterprise) で使用されている最新モデルを参照するスナップショットが新しいバージョンに切り替わった。

🏭

本番 API 用途には GPT-6.2 モデルファミリーを推奨

chat-latest は定期的に更新されるため、出力の安定性・再現性が必要な本番環境では GPT-6.2 系の固定モデルの利用が推奨されている。

🩺

ヘルスケアモデル構成の公開 Feature

Responses API (v1/responses) 向けに、選抜された OpenAI モデルと臨床的な質問に特化したハーネスを組み合わせた 4 つのモデル構成が公開された。

🔍

医療情報源の専用検索インデックス

ヘルスケアモデル構成が Web 検索を使用する際は、一般の Web ではなく医療情報源の専用インデックスを検索する。

主な内容

🔄 chat-latest の位置づけ

チャット用途の最新改善をいち早く試す目的で使用するスナップショット。基盤となるスナップショットは定期的に更新される。

🏭 本番利用の推奨

公式の案内では "We recommend leveraging the GPT-6.2 model family ... for production API usage" と、本番 API 用途には GPT-6.2 モデルファミリーが推奨されている。

🧰 臨床質問向けハーネス

ヘルスケアモデル構成は、選抜された OpenAI モデルに臨床的な質問向けに特化したハーネスを組み合わせた構成として提供される。

📚 医療専用の検索インデックス

Web 検索時は医療情報源の専用インデックスを参照する (原文: "it searches a dedicated index of medical sources")。

🩺 公開された 4 つのヘルスケアモデル構成 (v1/responses)

gpt-6.2-astra-healthcare
gpt-6.2-sol-healthcare
gpt-6-astra-healthcare
gpt-6.1-sol-healthcare

Before / After: ヘルスケア領域での Web 検索

Before: 汎用モデル + 一般 Web 検索

  • 臨床的な質問にも汎用ハーネスで対応
  • Web 検索は一般の Web を対象とし、医療情報の信頼性にばらつき
  • 医療特化の構成を独自に作り込む必要があった

After: ヘルスケアモデル構成

  • 臨床質問向けに特化したハーネスを標準で利用可能
  • Web 検索は医療情報源の専用インデックスを参照
  • モデル名を変更するだけで Responses API から利用できる

技術的な詳細

今回の変更点を整理すると以下のとおり。

変更点 内容
chat-latest スナップショット ChatGPT の最新モデルを参照するスナップショットが更新。定期的に更新されるため、再現性が必要な本番用途には GPT-6.2 系の固定モデルを推奨
ヘルスケアモデル構成 Responses API で gpt-6.2-astra-healthcare などのモデル構成名を指定可能に。臨床質問向けハーネスと医療専門の検索インデックスを使用
Python Responses API でヘルスケアモデル構成を指定する例 
from openai import OpenAI

client = OpenAI()

response = client.responses.create(
    model="gpt-6.2-astra-healthcare",
    input="高血圧治療における ACE 阻害薬と ARB の使い分けを教えてください。",
)
print(response.output_text)

※ モデル名に新しい構成名を指定するだけで、臨床質問向けハーネスと医療専用インデックスが利用できる。

開発者への影響・ユースケース

🔄 chat-latest 利用者: 本番環境では固定モデルへの移行を検討

スナップショット更新により応答の挙動が変わる可能性がある。出力の安定性や再現性が求められる本番環境では、GPT-6.2 モデルファミリーの固定モデルへの移行を検討すべき。

🩺 ヘルスケア領域の開発者: モデル名の変更だけで導入可能

Responses API でモデル名を gpt-6.2-astra-healthcare などに変更するだけで、臨床質問向けハーネスと医療専門の検索インデックスを活用できる。

🔍 検索品質の向上: 医療分野での情報の信頼性

ヘルスケアモデル構成の Web 検索は医療情報源の専用インデックスを参照するため、一般的な Web 検索に比べて医療分野での情報の信頼性向上が期待できる。

料金情報

💰 導入前に料金ページの確認を

ヘルスケアモデル構成は専用の価格体系が公開されているため、導入前に料金ページでの確認が必要。

まとめ

2026 年 11 月 24 日の API 更新では、chat-latest スナップショットの更新と、Responses API 向けヘルスケアモデル構成の公開が行われた。前者は ChatGPT の最新改善を API から試せる一方で本番用途には GPT-6.2 系が推奨される。後者は臨床質問向けハーネスと医療専門の検索インデックスを備えた 4 種類のモデル構成を提供し、ヘルスケア領域のアプリケーション開発における信頼性の高い情報取得を後押しする更新となっている。
