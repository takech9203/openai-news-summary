Astra for Law の発表: 法律業務向けフロンティアインテリジェンス

📅 2026-09-17 | ソース: OpenAI News/Blog

概要

⚖️

法律業務向けの新しい AI 基盤「Astra for Law」

最新かつ最も強力なモデル GPT-6 Astra に、プロフェッショナルな法律業務向けに調整された設定、ツール、コンテキストを組み合わせた基盤。法律事務所やリーガルテック企業が自らの専門性を軸に AI 製品やワークフローを構築できます。

🏗️

API 顧客による構築が可能

Harvey や Legora などの API 顧客は Astra for Law 上に構築し、自社の製品やワークフローにこのインテリジェンスを取り込むことができます。

🔐

プライバシーとガバナンス管理の拡充

機密性の高いクライアント業務のために、法律事務所向けのプライバシーとガバナンスの管理機能を拡充しました。

🔌

26 個の新しいエコシステムプラグイン

Relativity や Clio など、事務所が既に利用している専門ツールと ChatGPT を接続する 26 個の新しいエコシステムプラグインを提供します。

主要機能

🧠 法律向けフロンティアインテリジェンス

GPT-6 Astra に強力なリーガルサーチインデックスと、法的分析・文書作成のためのインストラクションを組み合わせたもの。法律実務全体で Astra の能力を増幅しつつ、事務所やリーガルテック企業が独自のアプリケーションやワークフローを自由に構築できます。

🔍 リーガルサーチインデックス

2 億 3,000 万件以上の URL からなるコーパスを通じて、米国の判例法、制定法、規則、裁判所規則、行政決定を検索でき、情報源は毎日追加されます。Thomson Reuters などのライセンスコンテンツや専門製品を補完する位置づけです。

🤝 Free Law Project との協業

CourtListener を運営する非営利団体 Free Law Project との協業により、公刊された米国の先例的判例法の 99.9% 以上をカバーする判例コレクションがリサーチ体験に統合されています。

📝 エンドツーエンドの法律ワークフロー

カスタムインストラクションにより、リサーチ結果をクライアントの事実関係に適用し、主張やディール条件を組み立て、弱点や不確実性を特定。判決の主文 (holding) とその他の説示の区別、主張を弱める判例への対処、契約の例外条項によるリスク移転の説明が可能です。類似の事実パターンを持つ有効な判例の特定では、他のフロンティアモデルよりも優れた性能を示しました。

🚀 提供形態

まず選定された法律事務所に対して ChatGPT と Codex の Trusted Access を通じて提供され、API にも近日対応予定。モデルピッカーでは「GPT-6 Astra Law」、API では gpt-6-astra-law として表示されます。

リーガルグレードの信頼性と管理機能

法律事務所はクライアントの秘密を保護し、実務における AI の利用方法を管理する必要があります。OpenAI は適格な法律事務所向けに Trusted Access Program を新設し、弁護士とその監督下で働く人々が法律業務のために Astra for Law を利用できるようにしました。適格な事務所には以下が提供されます。

  • API における Zero Data Retention (ZDR)
  • ChatGPT Enterprise の利用はデフォルトで人間によるレビュー対象から除外
Latham & Watkins との協力: AI ガバナンスのリーダーである Latham & Watkins と協力し、情報アクセス権限、エシカルウォール、クライアント指示、事務所による監督の設計に取り組んでいます。

事務所の専門性を軸にした ChatGPT の構築

OpenAI のフォワードデプロイドエンジニアは、選定された事務所と協力して、ChatGPT Enterprise にカスタムインターフェースと独自データへの統合を組み込み、各事務所のワークフローに合わせたツールを構築してきました。

📄

Sullivan & Cromwell: 契約書アナライザー

事務所の交渉プレイブックと厳選された先例を新規案件のレビューに取り込む契約書アナライザーを構築。条項を組み合わせて読んだときに浮かび上がるリスクを特定し、修正案 (レッドライン) やクライアント向け助言のドラフトに変換します。

🗂️

Ropes & Gray: ディールデューデリジェンスシステム

弁護士がデータルームを精査する方法に沿ったデューデリジェンスシステムを構築。調査結果を情報源まで遡って確認でき、主要顧客契約に通知・同意条項があるかなど、買収に影響し得る論点を特定します。

📈

Cooley: GO Public

キャピタルマーケッツの専門知識を企業の上場準備に活かす「GO Public」を構築。IPO 申請書類のドラフトから経営陣が注目すべきリスクの特定までを支援し、ディール内容が変わればその変更を申請書類全体に反映します。

法律分野で最も信頼されるツールとの接続

事務所が既に利用しているツールや知識をさらに活用するため、パートナー構築の 26 個のプラグインを公開しました。

長期的な投資

OpenAI は法律分野に長期的に投資しており、厳密な評価と弁護士・リーガルテックパートナーからのフィードバックに基づいて、Astra for Law のモデル、設定、ツール、インストラクションを継続的に改善していきます。Wachtell, Lipton, Rosen & Katz との協業では、同事務所の訴訟・企業法務の専門性と OpenAI のフロンティア研究を組み合わせ、高度な法的判断を支援する AI の可能性を探求しています。

開発者への影響

🔧 API での提供予定

gpt-6-astra-law として API での提供が予定されており、リーガルテック企業は法律特化のフロンティアインテリジェンスを自社製品に組み込めるようになります。

🎯 リサーチ精度の向上

リーガルサーチインデックスとの組み合わせにより、Web 検索のみの構成と比べて法律リサーチの正確性が相対 40% 改善しており、法律ドメインの AI アプリケーションの品質基盤が強化されます。

🛡️ エンタープライズ級のデータ保護

適格な事務所向けの Zero Data Retention (ZDR) と人間によるレビューのデフォルト除外により、機密性の高い法律業務でも利用しやすくなります。

🧩 オープンで組み合わせ可能なエコシステム

26 個のパートナープラグインとコミュニティプラグインにより、既存の法務ツールとの統合や、事務所独自のスキル開発の余地が広がります。

まとめ

Astra for Law は、GPT-6 Astra を核に、2 億 3,000 万件以上の URL を対象とするリーガルサーチインデックスと法律特化のインストラクションを組み合わせた、法律業務向けの新しい AI 基盤です。Vals AI のベンチマークで Web 検索のみの構成に対し相対 40% の正確性改善を示し、Trusted Access Program による ZDR などのリーガルグレードの管理機能、26 個のエコシステムプラグイン、大手法律事務所との協業事例を伴って発表されました。まず選定された法律事務所向けに ChatGPT と Codex で提供され、API (gpt-6-astra-law) にも近日対応予定です。
