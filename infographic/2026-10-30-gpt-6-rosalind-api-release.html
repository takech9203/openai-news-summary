GPT-6 Rosalind を API でリリース
生命科学研究向けの生物学的推論特化モデル

科学ツール利用を伴う専門的な生物学的推論を、複雑なライフサイエンス研究へ — Rosalind ファミリーのフラッグシップが GPT-6 世代に更新

📅 2026-10-30 | ソース: OpenAI API Changelog | カテゴリ: API 更新 / 新モデル

Model ID: gpt-6-rosalind

概要 — キーポイント

🧬

生物学的推論に特化した新モデル

複雑なライフサイエンス研究に向けて、科学ツール利用を伴う専門的な生物学的推論をもたらすモデル「GPT-6 Rosalind」(モデル ID: gpt-6-rosalind) が API Changelog で発表された

🔐

信頼アクセスプログラム経由の限定提供

一般公開ではなく、信頼アクセスプログラム (trusted access program) を通じて Rosalind Research 層に承認された組織のみが利用できる

🛠️

Work、Codex、API で利用可能

承認済み Research 組織の限定セットで Work と Codex、および別途承認された API で利用可能。Chat タブでは利用不可で、API 利用は内部研究ツール・ワークフロー・アプリケーションに限定される

💰

既存 Rosalind モデルの 3 倍の料金設定

入力 $15.00 / 出力 $75.00 (短コンテキスト、1M トークンあたり) と既存 Rosalind モデルの 3 倍の基本料金。既存モデルにはない 272K 超の長コンテキストにも対応する

📈

ライフサイエンス特化路線の最新アップデート

2026 年 4 月の GPT-Rosalind 初公開、同年 10 月 15 日の Rosalind Academic Plan 発表に続き、Rosalind ファミリーのフラッグシップが GPT-6 世代に更新された

主要機能・特徴

🧠 専門的な生物学的推論

複雑なライフサイエンス研究向けに、専門的な生物学的推論 (specialized biological reasoning) を提供。フロンティア生物学研究を対象とする Rosalind Research 層向けのフラッグシップモデル

🔬 科学ツール利用

科学ツール利用 (scientific tool use) を伴う推論が特徴。なお、固有の追加パラメータや科学ツール利用のインターフェース仕様は公式ドキュメントでは確認できておらず、承認後に提供される情報を参照する必要がある

🛡️ 信頼アクセスプログラム

Enterprise または Business 契約を持つ適格組織が申請し、OpenAI が審査のうえ Research / Discovery のアクセス層を判定。組織検証・審査・利用サーフェス限定という多層管理で段階的に提供される

📏 長コンテキスト対応

272K 入力トークン超の長コンテキストを料金表上でサポート。既存の Rosalind モデル (短コンテキストのみ提供) にはない特徴

🗓️ 段階的ロールアウト

Enterprise ワークスペースでは 2 週間の Admin Preview から開始し、その期間中はデフォルトでオフ。組織内での利用開始には管理者による有効化作業が必要

2 つのアクセス階層と申請手順

Enterprise または Business 契約を持つ適格組織が信頼アクセスプログラムを通じて申請でき、OpenAI が以下のいずれのアクセス層に適格かを判定します。

アクセス層 対象 利用モデル
Rosalind Research フロンティア生物学研究 GPT-6 Rosalind Research、GPT-5.5 Rosalind Research
Rosalind Discovery 文献レビュー、データ解析、科学コード作成、実験計画などの日常的研究 既存の Rosalind 5.5 モデル (より厳格な監視と Discovery 専用セーフガードが適用)
⚠️ 階層間の移行に注意 Discovery 承認は Research アクセスを付与せず、Research への移行には追加審査が必要。米国大学の学術ラボは別枠の Rosalind Academic Plan で申請するが、同プランには API アクセスは含まれない。
1

組織に紐づくアカウントでサインインし、アクセス申請フォームを開く

2

組織を選択し、組織検証を完了する

3

研究内容・利用目的の情報を提出し、データ取扱オプションと提出声明を確認する

4

申請を送信し、表示される次のステップに従う

📝 申請者には組織を代表する権限が必要 (ワークスペースのオーナー / 管理者である必要はない)。最終承認は検証済みのオーナー / 管理者が別途行い、規約への同意、価格の確認、有効化の承認を完了させる必要があります。

提供範囲と利用形態

利用できる

  • Work (承認済み Research 組織の限定セット)
  • Codex
  • 別途承認された API (承認済みの内部研究ツール・ワークフロー・アプリケーションに限定)

利用できない / 禁止

  • Chat タブでは利用不可
  • 顧客向け製品や外部商用アプリケーションでの API 利用は現時点で不可
  • 認証情報の共有や、外部ユーザーへのモデルアクセス提供は禁止
  • Amazon Bedrock (AWS) では現在利用不可
📝 Enterprise ワークスペースでは 2 週間の Admin Preview から開始 (期間中はデフォルトでオフ)。API 組織へのメンバー追加は API Platform → Settings → People から行う (手動管理の場合)。

コードサンプル

承認済みの API 組織では、モデル ID gpt-6-rosalind を指定して利用します。以下は基本的な呼び出し例です。

Python GPT-6 Rosalind の基本的な呼び出し例 
from openai import OpenAI

# 承認済みの API 組織のキーを使用する
client = OpenAI()

response = client.chat.completions.create(
    model="gpt-6-rosalind",
    messages=[
        {
            "role": "system",
            "content": (
                "You are a life sciences research assistant specializing in "
                "biological reasoning for complex research questions. "
                "Provide evidence-based analysis."
            ),
        },
        {
            "role": "user",
            "content": (
                "Compare the mechanisms of mRNA degradation pathways in "
                "mammalian cells and outline an experimental design to "
                "distinguish their relative contributions for a given transcript."
            ),
        },
    ],
)

print(response.choices[0].message.content)
📝 上記は承認済み組織での一般的な API 利用パターンを示す例であり、gpt-6-rosalind 固有の追加パラメータや科学ツール利用のインターフェース仕様は公式ドキュメントでは確認できていません。実際の仕様は信頼アクセスプログラム承認後に提供される情報を参照してください。

ユースケース — 開発者への影響

🔬 内部研究ツール・解析パイプラインへの組み込み

Rosalind Academic Plan では API アクセスが含まれなかったのに対し、Rosalind Research 承認組織は別途承認を得たうえで gpt-6-rosalind を API から呼び出せるため、内部研究ツールや解析パイプラインへの組み込みによる自動化が可能になる。ただし用途は承認済みの内部研究ツール・ワークフロー・アプリケーションに限られ、顧客向け製品や外部商用アプリケーションへの組み込みは現時点で認められていない。

💰 キャッシュ活用によるコスト設計

入力 $15.00 / 出力 $75.00 (短コンテキスト、1M トークンあたり) と既存 Rosalind モデルの 3 倍の料金設定であり、272K 入力トークンを超える長コンテキスト利用ではさらに 2 倍 (入力) / 1.5 倍 (出力) になる。キャッシュ済み入力 ($1.50) やキャッシュ書き込みオプションの活用がコスト最適化の鍵となる。

🗂️ アクセス層とロールアウトを踏まえた導入計画

Enterprise ワークスペースでは 2 週間の Admin Preview (デフォルトオフ) から始まるため、組織内での利用開始には管理者による有効化作業が必要。また Discovery 承認では GPT-6 Rosalind は利用できず、Research への移行には追加審査が必要となるため、アクセス層の違いを理解して導入を計画する必要がある。

まとめ

GPT-6 Rosalind (gpt-6-rosalind) は、複雑なライフサイエンス研究向けに科学ツール利用を伴う生物学的推論を提供する、Rosalind ファミリーの最新フラッグシップモデルである。信頼アクセスプログラムで Rosalind Research 層に承認された組織のみが、Work、Codex、および別途承認された API (内部研究用途限定) を通じて利用できる。

「trusted access」戦略を体現したリリース 組織検証・アクセス層の審査・利用サーフェスの限定という多層的な管理のもとで段階的に提供

料金は既存 Rosalind モデルの 3 倍 (入力 $15.00 / 出力 $75.00、1M トークンあたり) に設定され、272K 入力トークン超の長コンテキストにも対応する。機微な生物学的能力を持つモデルを多層的な管理のもとで段階的に提供する、OpenAI のライフサイエンス特化路線の最新アップデートである。
