新機能 コンプライアンス / 組織管理

🏥 API 組織設定に HIPAA コンプライアンス対応のプロダクト内フローを追加

対象組織の管理者は、標準 BAA (Business Associate Agreement) をプロダクト内で直接承諾し、HIPAA コンプライアンスサポートを有効化できるように

📅 2026-10-05 | ソース: OpenAI API Changelog

概要

🖥️

プロダクト内 BAA 承諾フローの追加

API 組織設定 (Organization settings > General) に HIPAA コンプライアンス対応のためのプロダクト内フローが追加された

✍️

セルフサービスで標準 BAA を承諾

対象組織の管理者 (Admin / Owner) は OpenAI の標準 BAA をプロダクト内で直接承諾できる。従来の営業・サポート経由の個別手続きは不要に

🏢

組織単位で HIPAA サポートを有効化

BAA の承諾により、組織の HIPAA コンプライアンスサポートが有効化され、対象サービスで PHI (保護対象保健情報) を扱う構成が可能になる

⚡

ヘルスケア分野のリードタイム短縮

BAA 締結の手続きが簡素化され、ヘルスケア分野での API 利用開始までのリードタイムが大幅に短縮される

📋

対象要件・設定要件の事前確認が必要

すべての組織が無条件に有効化できるわけではなく、対象要件、カバーされるサービス、設定要件 (データ保持設定など) をヘルプセンターで確認する必要がある

"Added an in-product flow for HIPAA compliance support in API Organization settings > General." — "Admins of eligible organizations can now accept the standard Business Associate Agreement (BAA)" (OpenAI API Changelog)

Before / After: BAA 手続きの変化

Before (従来)

  • 営業窓口やサポート経由で BAA の締結を申請する必要があった
  • 個別の手続きに時間を要し、PHI を扱う開発の着手が遅延
  • ヘルスケア分野での API 利用開始までのリードタイムが長い

After (今回の変更後)

  • 対象組織の管理者がプロダクト内で標準 BAA を直接承諾
  • セルフサービスで即座に HIPAA コンプライアンスサポートを有効化
  • ヘルスケア開発の着手までのリードタイムが大幅に短縮

主なポイント

📍 設定場所

API 組織設定の「General」セクション (Organization settings > General)。platform.openai.com の組織設定ページからアクセスできる

👤 操作可能なロール

対象組織の管理者 (Admin / Owner) のみが BAA 承諾フローを操作できる

📜 承諾対象

OpenAI の標準 BAA (Business Associate Agreement、事業提携契約)。HIPAA が義務付けるベンダーとの契約をプロダクト内で締結

✅ 有効化の効果

組織単位で HIPAA コンプライアンスサポートが有効化され、BAA 対象サービスで PHI を扱う構成が可能になる

🔍 対象要件の確認

対象要件 (eligibility)、カバーされるサービス、設定要件が定められており、詳細はヘルプセンターの BAA 記事で確認する

HIPAA と BAA の背景

⚖️ HIPAA とは

Health Insurance Portability and Accountability Act。米国における医療情報のプライバシーとセキュリティを定める法律

🔐 PHI とは

Protected Health Information (保護対象保健情報)。医療機関などの対象事業者 (Covered Entity) が取り扱う保護対象の医療情報

🤝 BAA とは

対象事業者が PHI を外部ベンダー (Business Associate) に取り扱わせる場合、そのベンダーとの間で締結が義務付けられている契約

💡 OpenAI API を利用して PHI を処理するヘルスケア関連アプリケーションを構築する場合、開発者の組織は OpenAI と BAA を締結する必要がある。

技術詳細: BAA 承諾フロー

今回の変更は API のエンドポイントやパラメータの変更ではなく、プラットフォームの組織管理機能の拡張である。有効化の流れは以下のとおり。

1

組織設定にアクセス: 組織の管理者が Organization settings > General にアクセス

2

対象要件を確認: HIPAA コンプライアンスサポートのセクションで対象要件 (eligibility) を確認

3

標準 BAA を承諾: 標準 BAA の内容を確認し、プロダクト内で承諾

4

HIPAA サポート有効化: 組織の HIPAA コンプライアンスサポートが有効化され、対象サービスで PHI を扱う構成が可能に

ユースケース / 開発者への影響

🏥 医療機関向け AI アプリケーションの迅速な立ち上げ

電子カルテの要約や診療記録の分析など、PHI を扱うヘルスケアアプリケーションの開発において、BAA 締結のセルフサービス化により開発着手までのリードタイムが短縮され、医療分野での API 活用が容易になる。

🧑‍⚕️ ヘルスケアスタートアップのコンプライアンス対応

従来必要だった営業・サポート経由の個別手続きが不要になり、対象組織はプロダクト内で即座に標準 BAA を承諾できる。小規模なチームでも HIPAA 準拠のサービス構築を迅速に開始できる。

🛡️ 組織管理者によるコンプライアンス管理

有効化の前に、対象要件、BAA がカバーするサービスの範囲、必要な設定要件 (データ保持設定など) をヘルプセンターで確認する。BAA を承諾しても、アクセス制御やログ管理など開発者自身の HIPAA 対応義務は引き続き残る点に注意が必要。

まとめ

OpenAI は API 組織設定に HIPAA コンプライアンス対応のプロダクト内フローを追加し、対象組織の管理者がセルフサービスで標準 BAA を承諾できるようにした。ヘルスケア分野で OpenAI API を利用する開発者にとって、BAA 締結の手続きが大幅に簡素化される重要なアップデートである。有効化にあたっては、対象要件、カバーされるサービス、設定要件をヘルプセンターで事前に確認することが推奨される。
