API 更新 価格改定

API アップデート: リクエスト単位のリージョン処理選択と GPT-5.6 Sol の値下げ

📅 発表日: 2026 年 8 月 21 日 | ソース: OpenAI API Changelog

Global ジオグラフィのプロジェクトからプレフィックス付きドメイン (us.api.openai.com / eu.api.openai.com など) を使うだけで、リクエストごとに処理リージョンを選択可能に。あわせて GPT-5.6 Sol が入力 20% 減・出力 33% 減に値下げ。コンプライアンスとコストの両面で開発者に恩恵をもたらすアップデート。

📋 概要 - キーポイント

🌍

リクエスト単位のリージョン処理選択

Global ジオグラフィのプロジェクトの API キーで、プレフィックス付きドメイン (例: us.api.openai.com、eu.api.openai.com) を使うことにより、リクエスト単位でリージョン処理 (regional processing) を選択できるようになった。

🗂️

リージョン専用プロジェクトが不要に

これまでのようにリージョン専用プロジェクトを分けて作成する必要がなく、単一のプロジェクトからリクエストごとに処理リージョンを切り替えられる。base_url の変更だけで導入できる。

💰

GPT-5.6 Sol の価格改定

入力トークンが $4/100 万トークン (20% 減)、出力トークンが $20/100 万トークン (33% 減) に値下げされた。

📆

プロモーション価格の期限

新価格はプロモーション価格として少なくとも 2026 年 11 月 21 日まで提供される ("GPT-5.6 Sol's promotional pricing is available at least through November 21, 2026.")。

🏛️ 主要機能 - 今回のアップデート 2 本柱

FEATURE

🌍 リクエスト単位のリージョン処理選択

Changelog では "API customers can now select regional processing for an individual request by using a prefixed domain with an API key" と説明。Global ジオグラフィに設定されたプロジェクトの API キーを、リージョンプレフィックス付きドメインに対して使用することで、そのリクエストのみを指定リージョンで処理・保存できる。

  • 単一プロジェクトでの切り替え: リージョンごとにプロジェクトや API キーを分ける必要がなく、base_url の変更だけでリクエスト単位にリージョンを選択できる
  • 既存要件の継続適用: "Existing eligibility, data retention control, endpoint, and model support requirements continue to apply." とあるとおり、利用資格、データ保持コントロール (ZDR / Modified Abuse Monitoring など)、エンドポイント、モデルの各対応要件は従来どおり適用される
  • 対応の前提条件: エンドポイントとモデルの両方が対象リージョンの regional processing に対応している必要がある
UPDATE

💰 GPT-5.6 Sol の価格改定

GPT-5.6 Sol の API 価格が値下げされた。プロモーション価格として少なくとも 2026 年 11 月 21 日まで適用される。

  • 入力トークン: $5 → $4 / 100 万トークン (20% 減)
  • 出力トークン: $30 → $20 / 100 万トークン (33% 減)
  • 適用期間: 少なくとも 2026 年 11 月 21 日まで
  • 既存利用者: 変更なしで自動的に新価格が適用される

(改定前の価格は Changelog に明記されていないが、値下げ率からの逆算による)

⚠️ 実質的に有効なリージョン

リクエスト単位のリージョン選択は「処理 (processing)」の対応が前提のため、現時点で実質的に有効なのは米国・欧州・UAE (UAE は gpt-5.6-luna など特定スナップショットに限定) である。

💡 TLS 終端もリージョン内で完結

us.api.openai.com と eu.api.openai.com 宛のリクエストは、Cloudflare Regional Services により TLS 終端も選択リージョン内で行われる。

⚙️ 技術詳細

💻 コードサンプル

公式ガイドの例に沿った、単一クライアントでリクエストごとにリージョンを切り替える例。API キーは Global ジオグラフィのプロジェクトのものを使用する。

Python リクエスト単位でリージョンを切り替える 
from openai import OpenAI

# Global ジオグラフィのプロジェクトの API キーを使用
client = OpenAI()

# 1. リージョン制約なし (グローバル、デフォルトの api.openai.com)
resp_global = client.responses.create(
    model="gpt-5.6-terra",
    input="Hello from anywhere!",
)

# 2. 米国で処理・保存
resp_us = client.with_options(
    base_url="https://us.api.openai.com/v1"
).responses.create(
    model="gpt-5.6-terra",
    input="Hello from the US region!",
)

# 3. EU で処理・保存
resp_eu = client.with_options(
    base_url="https://eu.api.openai.com/v1"
).responses.create(
    model="gpt-5.6-terra",
    input="Hello from the EU region!",
)

🎯 開発者への影響

  • 🌐 データレジデンシー対応の簡素化: 従来はリージョン処理を利用するためにリージョン専用プロジェクトを作成する必要があったが、Global ジオグラフィのプロジェクト 1 つで、リクエストごとに処理リージョンを選択できるようになった。ユーザーの所在地に応じて US / EU を動的に振り分けるマルチリージョンアプリの実装が容易になる
  • 🛠️ 導入コストが低い: SDK の base_url (Python なら client.with_options(base_url=...)) を切り替えるだけで利用でき、キー管理やプロジェクト構成の変更は不要
  • ✅ 要件の事前確認が必要: 利用資格・データ保持コントロール・エンドポイント・モデルの各対応要件は従来どおり適用されるため、使用するモデルとエンドポイントが対象リージョンの regional processing に対応しているかをガイドの対応表で確認する必要がある
  • 💸 GPT-5.6 Sol のコスト削減: 入力 20% 減・出力 33% 減により、特に出力トークンの多いワークロード (長文生成、エージェント用途など) でコストメリットが大きい。既存利用者は変更なしで自動的に新価格が適用される
  • ⏳ プロモーション価格の期限に留意: 新価格は「少なくとも 2026 年 11 月 21 日まで」のプロモーション価格であり、それ以降の価格は保証されていない。長期のコスト見積もりでは変動の可能性を考慮したい

💼 ユースケース

🌍 マルチリージョンアプリのデータレジデンシー対応

ユーザーの所在地に応じて US / EU を動的に振り分けるアプリケーションを、Global ジオグラフィのプロジェクト 1 つで実装。base_url を us.api.openai.com / eu.api.openai.com に切り替えるだけで、リクエストごとにデータレジデンシー要件へ柔軟に対応できる。

🏦 コンプライアンス要件のある業務システム

EEA + スイスの利用者向けデータは EU で、米国の利用者向けデータは米国で処理・保存する構成を、リージョン専用プロジェクトを分けずに構築。データ保持コントロール (ZDR / Modified Abuse Monitoring など) の要件は従来どおり適用されるため、対応表と併せて事前確認して運用する。

📝 出力トークンの多いワークロードのコスト削減

長文生成やエージェント用途など出力トークンの多いワークロードで、GPT-5.6 Sol の出力 33% 減 ($30 → $20 / 100 万トークン) のコストメリットを享受。既存コードの変更なしで自動的に新価格が適用される。

📝 まとめ

今回の更新は、コンプライアンスとコストの両面で開発者に恩恵をもたらす。リクエスト単位のリージョン処理選択により、Global ジオグラフィのプロジェクト 1 つで us.api.openai.com / eu.api.openai.com などのプレフィックス付きドメインを使い分け、データレジデンシー要件に柔軟に対応できるようになった。GPT-5.6 Sol は入力 $4 / 出力 $20 (100 万トークンあたり) へ値下げされ、少なくとも 2026 年 11 月 21 日までプロモーション価格が適用される。
