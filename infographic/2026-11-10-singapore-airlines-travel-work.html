導入事例 OpenAI API

✈️ シンガポール航空、OpenAI 技術で旅行体験と業務を進化

📅 2026-11-10 | ソース: OpenAI News

概要

💬

Kris チャットボットを LLM ベースへ移行

従来のダイアログフロー型から OpenAI API を使った会話型体験へ移行し、顧客満足度 (CSAT) が 2 倍に向上。AI 支援ツールにより担当者の平均処理時間も約 10% 削減。

🧭

自然言語で旅行を探索できる Flight Recommender

フィルタや日付を繰り返し調整する代わりに、希望する旅行を自然言語で記述。月間ユーザーは過去 1 年で約 3 倍に成長。

🛠️

ソフトウェア開発ライフサイクル (SDLC) に AI を導入

計画、要件の洗練、テスト、レビューを効率化し、対象とした SDLC 活動全体で最大 20% の生産性向上を達成。

🏢

社内 AI プラットフォーム「Jarvis」で全社展開

OpenAI モデルを搭載した Jarvis により、ガバナンスの効いた形で全従業員が AI を利用可能に。従業員の 60% 以上が毎月利用。

🛡️

責任ある AI 導入の一貫したアプローチ

オーケストレーション、内部データ制御、バリデーション、人間によるレビューを OpenAI モデルと組み合わせ、本番ワークフローへ導入。

Before / After: Kris チャットボットの移行

Before: ダイアログフロー型

  • すべてのトピックを手動でマッピング
  • すべてのフローを事前に記述する必要
  • カバレッジの拡大が困難
  • インテント未定義の場合、セルフサービスで処理できる要求でも担当者対応が必要になりがち

After: LLM ベース会話型

  • 自然言語による顧客インテントの解釈
  • ナレッジベースに基づいた回答の生成
  • 複数トピックにまたがる会話の管理
  • 必要時に関連コンテキストを添えて担当者へ引き継ぎ

主要な AI 活用領域

💬 Kris チャットボット

OpenAI API を使用した LLM ベースの会話型サポート。一般的な問い合わせ、特別リクエスト、リアルタイムのフライト運航障害情報、一部のトランザクション処理に対応。

  • 通話要約など担当者向け AI 支援ツールも導入
  • 今後は予約変更、手荷物関連、エージェント型のやり取りへ拡張予定

🧭 Flight Recommender

希望する旅行を自然言語で記述できる探索ツール。OpenAI API 上に構築され、運賃・空席データに接続されたオーケストレーション層がインテントを解釈し、パーソナライズされた提案を返す。

  • 今後は会話を重ねて旅行プランを洗練できる体験へ拡張準備中

🛠️ SDLC ワークフロー

コーディングにとどまらず、デリバリーライフサイクル全体で OpenAI モデルを活用。

  • 要件の洗練とステークホルダーセッションの分析
  • プロダクト仕様の作成
  • エッジケースの特定とテストケースの作成
  • アーキテクチャレビュー
  • 複雑な作業を小さなタスクへ分解

🏢 社内プラットフォーム Jarvis

OpenAI モデルを搭載した全社向け AI プラットフォーム。文書の要約からカスタムワークフローの作成まで、ガバナンスの効いた形で日常業務を支援。

  • セキュアな環境で PDF、Word、Excel、PowerPoint を横断的に活用
  • カスタムワークフローや軽量なナレッジベースを作成

🛡️ Flight Recommender のガードレール実装

  • 入出力のバリデーション
  • 悪意ある、または不適切なクエリへの対応
  • ハルシネーションの低減
  • PII (個人識別情報) の取り扱い
  • クエリごとに必要なコンテキストのみへの認証付きアクセス

開発者・企業への影響 / ユースケース

🔄 ダイアログフロー型から LLM 型への移行事例

事前定義フローに依存する従来型チャットボットを OpenAI API ベースの会話型体験へ移行することで、インテントのカバレッジ問題を解消し、CSAT を大幅に改善できることを実証。

🛡️ ガードレール設計の参考例

入出力バリデーション、不適切クエリ対応、ハルシネーション低減、PII の取り扱い、最小権限のコンテキストアクセスなど、本番導入に必要な安全対策の具体例を提示。

🛠️ SDLC 全体への AI 適用

コーディングにとどまらず、要件定義からテスト、アーキテクチャレビュー、本番監視まで AI を組み込むことで、人間が「作成者」から「指示・レビュー・検証者」へ役割を移行するモデルを提示。ある商用機能の開発では、開発開始前に OpenAI API で前提を検証し、曖昧な要件やエッジケースを洗い出した。

🏢 全社 AI 基盤の普及モデル

ガバナンスの効いた社内プラットフォーム (Jarvis) により、エンジニア以外の従業員にも AI 活用を広げられることを示す。

まとめ

シンガポール航空は、顧客向けの Kris チャットボットと Flight Recommender、従業員向けの Jarvis、そしてソフトウェア開発ライフサイクルという 4 つの領域で OpenAI 技術を本番活用し、CSAT 2 倍、平均処理時間約 10% 削減、SDLC 生産性最大 20% 向上などの定量的成果を上げている。オーケストレーション、データ制御、バリデーション、人間によるレビューを組み合わせた責任ある AI 導入アプローチは、エンタープライズでの LLM 活用の実践的なモデルケースといえる。今後は Kris のトランザクション機能拡充や Flight Recommender の会話型体験化など、さらに深いセルフサービスへの拡張が予定されている。
