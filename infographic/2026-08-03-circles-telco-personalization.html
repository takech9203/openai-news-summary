導入事例 (Customer Story)

Circles、OpenAI 技術で通信事業のパーソナライゼーションを実現

ARPU 22% 向上・解約率 9% 削減 — AI ネイティブな通信事業スタックの構築

📅 2026-08-03 | ソース: OpenAI News

概要

シンガポール発のテクノロジー企業 Circles は、OpenAI API と Codex を活用して「AI ネイティブな通信事業スタック」を構築。サポート・パーソナライゼーション・オペレーション・マネタイゼーションをリアルタイムに連携させ、豊富な顧客シグナル (利用状況・請求・ネットワーク・位置情報) をタイムリーなアクションに変換するという通信業界の長年の課題を解決した。

💬

AI Concierge — 対話型インターフェース

OpenAI API プラットフォームを基盤に、検索・アカウント管理・サポート・レコメンデーションを単一の体験に統合。顧客のリアルタイムな文脈を理解して問題を解決する。

📈

ARPU +22%・解約率 -9% (シンガポール)

AI パーソナライゼーションにより、ユーザー 1 人あたりの平均収益が 22% 向上し、解約率 (チャーン) が 9% 減少した。

🤖

CareX — 自律解決率 65% のマルチエージェント

AI Concierge を支えるマルチエージェントアーキテクチャ「CareX」は、カスタマーサポートで 65% の自律解決率を達成している。

⚡

Codex で開発効率 +29%

社内開発でも Codex を活用し、設計・コーディング支援・テストの加速により開発効率が 29% 向上した。

🛡️

ガバナンスを中核に据えた設計

PII 暗号化・スコープ限定アクセス・段階的ロールアウトなど、規制産業での大規模 AI 運用に必要な統制を実装している。

Before / After — 通信サポート体験の再構築

Before: 従来の受動的サポート

  • 顧客がメニューを辿る必要がある
  • 情報を何度も繰り返し伝える
  • 問題発生後に対応を待つ
  • 画一的なキャンペーン配信
  • 単純な回答のみの従来型チャットボット

After: AI Concierge による能動的体験

  • 検索・アカウント管理・サポート・推奨を単一体験に統合
  • リアルタイムな文脈 (ローミング閲覧中・請求調査中など) を理解
  • 適切なスペシャリストエージェントへ自動ルーティング
  • ハイパーパーソナライズされたレコメンデーション
  • 「理解し、行動し、解決する」エージェント設計

主要コンポーネント

💬 AI Concierge

OpenAI API 上に構築された対話型インターフェース。検索、アカウント管理、サポート、パーソナライズされたレコメンデーションを単一の体験に統合。顧客のリアルタイムな文脈を理解し、適切なスペシャリストエージェントへルーティングして、情報の繰り返しなしに問題を解決する。

🤖 CareX (マルチエージェント)

顧客の履歴と現在のアクティビティを理解するオーケストレーションエージェントと、請求・サブスクリプション・ネットワーク管理・アカウントサービスを担うスペシャリストエージェントを組み合わせ。エージェントは解決に必要な情報のみを受け取り、必要に応じて完全な文脈を添えて人間へエスカレーションする。

🎯 Xplore IQ (パーソナライゼーション)

OpenAI API 上に構築された AI パーソナライゼーションエンジン。顧客の行動・アカウント履歴・リアルタイムシグナルを組み合わせ、ローミングパックやプランアップグレードの推奨からチャーン防止まで、最も関連性の高い「次のアクション」を特定。効果は AI 群と非 AI 群の比較で測定された。

⚡ Codex (社内開発)

エンジニアリング・情報セキュリティ (infosec)・インシデント管理の各チームが、設計・コーディング支援・テストの加速に Codex を活用。検証と最終レビューはスペシャリストが責任を持つ体制を維持しつつ、開発効率を 29% 向上させ、エンジニアが付加価値の高いイノベーションに集中できるようにした。

🛡️ ガバナンスレイヤー

顧客情報がモデルレイヤーに到達する前に自動制御を適用。LLM に渡す前に個人識別情報 (PII) を特定・暗号化し、スペシャリストエージェントには特定タスクに必要な情報へのスコープ限定アクセスのみを付与する。

ガバナンスの重視

通信事業者向けの AI 構築には、顧客と事業者双方を守るセーフガードが必要となる。

🔐

PII の特定・暗号化

顧客情報がモデルレイヤーに到達する前に自動制御を適用し、LLM に渡す前に個人識別情報を特定・暗号化する

🎚️

スコープ限定アクセス

スペシャリストエージェントには、顧客プロファイル全体への無制限アクセスではなく、特定の解決タスクに必要な情報のみを付与

🙋

人間へのエスカレーションパス

AI エージェントは必要に応じて、完全な文脈を添えて人間のエージェントへシームレスにエスカレーション

🚦

運用コントロール

段階的ロールアウト、レート制限、ロールバックメカニズム、商用セーフガードにより、通信環境全体への拡大時も統制を維持

開発者・企業への影響

🧩 マルチエージェント設計の実例

顧客履歴を理解するオーケストレーションエージェントとドメイン特化のスペシャリストエージェントを組み合わせる構成は、大規模なカスタマーサポート自動化の参考パターンとなる。

📏 効果測定の手法

AI レコメンデーションを受けたグループと受けていないグループの比較により ARPU +22%、解約率 -9% を測定しており、AI 施策の ROI を定量評価する好例となっている。

📶 段階的な自律化

初週 55% から現在 65%、目標 95% という段階的な自律解決率の向上は、人間へのエスカレーションを維持しながら AI の対応範囲を広げるアプローチを示している。

🛡️ ガバナンス設計

LLM へ渡す前の PII 特定・暗号化、エージェントへのスコープ限定アクセス、段階的ロールアウト、レート制限、ロールバックといった規制産業での AI 運用に必要な統制の実装例を提供している。

⚙️ Codex の社内活用

顧客向け製品と並行して開発チームの生産性向上 (+29%) に Codex を使う、二面的な AI 活用モデルを示している。

今後の展望

  • OpenAI とともに AI ネイティブ通信スタックの拡張を継続し、CareX のオブザーバビリティ強化を推進
  • 顧客とのやり取りをより自然でアクセスしやすくするリアルタイム音声サポートの導入を計画 (テキスト + 音声で自律解決率 95% を目標)
  • 長期的には、従来のアプリナビゲーションを超えた対話型で文脈を理解する通信体験を構想し、事業者の能動的でパーソナライズされた顧客エンゲージメントを支援

まとめ

Circles は OpenAI API を基盤に、マルチエージェントアーキテクチャ「CareX」とパーソナライゼーションエンジン「Xplore IQ」からなる AI ネイティブな通信スタックを構築し、シンガポールで ARPU +22%、解約率 -9%、カスタマーサポートの 65% 自律解決という定量的な成果を実証した。社内では Codex により開発効率を 29% 向上させ、PII 暗号化やスコープ限定アクセスなどのガバナンスを中核に据えた設計は、規制産業における大規模 AI 導入のモデルケースとなっている。今後はリアルタイム音声サポートの導入により、ワークフロー全体で 95% の自律解決を目指す。
