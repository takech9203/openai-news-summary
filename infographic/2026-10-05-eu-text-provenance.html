EU テキスト来歴ルールへの OpenAI のアプローチ

テキスト透かし "textGrain" の段階的展開 — EU AI 法の「機械可読な識別」要件に対応

📅 2026-10-05 | ソース: OpenAI News

概要

🇪🇺

EU AI 法のテキスト来歴要件に対応

「生成テキストを機械可読な形で識別可能にする」要件に応えるため、テキスト透かしへの段階的アプローチを発表。画像・音声で公開済みの検証ツールに続き、来歴の取り組みをテキストへ拡張する。

💧

独自透かし技術 "textGrain"

モデルの単語選択に不可視の統計的シグナルを埋め込む。Google の SynthID for text を含む他のアプローチと同等以上の性能を確認。テクニカルレポートを公開済みで、オープンソース化も計画。

🪜

3 本柱の段階的展開

(1) API 顧客向けグローバル・オプトイン、(2) EU 域内の ChatGPT / Codex 出力への不可視透かし追加、(3) 検出ツールは承認済み研究者・専門機関への限定アクセスから開始する。

📉

技術的限界を明示

短いテキスト・語彙選択の自由度が低い分野・編集後のテキストでは検出率が大幅に低下する。この限界が、検出ツールを当初一般公開しない判断の根拠となっている。

🔍

「何を示し、何を示さないか」の透明性

透かしは人間の貢献度・所有権・ユーザー特定・正確性を証明しない。検出結果から導ける結論の限界を周知することを重視している。

段階的展開の 3 本柱

1

API 顧客向けオプトイン本日から

世界中の API 顧客が、対象モデルについてテキスト透かしをオプトインで有効化できる。API ではデフォルトでは無効のまま。クラウドパートナー経由の OpenAI モデル出力への対応も数週間以内に展開予定。

2

EU 域内での透かし付与数週間以内

EU の対象となる ChatGPT および Codex のテキスト出力に、全プラン対象で不可視透かしを追加。グローバルなデフォルト化は行わず、EU 限定の地域的アプローチで実運用からの学習とフィードバック収集を優先する。

3

検出ツールへの研究者限定アクセス申請受付開始

EU の Code of Practice に沿って、当初は承認済みの研究者・専門機関にケースバイケースで提供し、技術の評価と改善に役立てる。誤検出 (偽陽性) と見逃し (偽陰性) のリスクを踏まえ、ローンチ時点では一般公開しない。

補足: この限定アクセスはテキスト来歴のみに適用。画像・音声向けの検証ツール (openai.com/verify および Content Provenance API) は引き続き一般の組織が利用できる。

Before / After: コンテンツ来歴の対応範囲

Before: 画像・音声のみ

  • 画像への Content Credentials (C2PA 準拠) 付与
  • 画像・音声への不可視 SynthID 透かし
  • openai.com/verify と Content Provenance API による検証
  • テキストは来歴シグナルの対象外

After: テキストへ拡張

  • 独自技術 textGrain によるテキスト透かしを開始
  • API はグローバル・オプトイン (デフォルト無効)
  • EU の ChatGPT / Codex は全プランで有効化へ
  • 検出ツールは研究者・専門機関に限定提供

主要ポイント

💧 textGrain の仕組み

モデルの単語選択に不可視の統計的シグナルを埋め込み、検出器がそのシグナルを探索して OpenAI の透かしの有無を評価する。エントロピー調整型の透かし手法としてテクニカルレポートを公開済み。

🏆 他手法と同等以上の性能

OpenAI の評価では、textGrain は Google の SynthID for text を含む他のアプローチと同等以上の性能を示した。ただし理想的条件下での高性能が日常利用での信頼性を保証するわけではないと明記。

🌍 オープンソース化を計画

textGrain はオープンソースとして公開予定。独自の透かし実装や研究の基盤として活用できる見込みで、テクニカルレポートも今後数週間で追記される予定。

📊 出力品質への影響なし

最新フロンティアモデル Astra を用いたベンチマーク評価では、透かしの有無による有意な性能差は見られなかった (GPQA Diamond、Terminal-Bench 4.0 など 8 項目で確認)。

🧅 多層的な来歴アプローチ

単一の来歴技術では不十分であるため、オープン標準 (C2PA)・耐久性のある透かし・検証ツールを組み合わせる。Content Credentials と不可視透かしは補完関係にある。

技術詳細: 透かしの埋め込みと検出のフロー

多層的なコンテンツ来歴アプローチ

🪪対応する画像出力への Content Credentials の付与 (C2PA 準拠)。ファイルの出所と履歴を記録できる。
🎵対応する画像・音声への不可視 SynthID 透かしの埋め込み。メタデータが除去されてもシグナルを保持できる。
✅openai.com/verify と Content Provenance API による画像・音声の検証提供。
ポイント: テキストは書き換え・翻訳・編集が容易であるため、来歴の拡張にはこうした実務的限界の考慮が必要とされる。Content Credentials と不可視透かしは補完関係にある。

テキスト透かしが示さないこと

OpenAI は、検出結果から導ける結論の限界について以下を強調している。

✕人間の貢献度は測定できない: OpenAI システムが文章の一部を生成・処理したことは示せても、人間の判断・編集・創造性がどの程度加わったかは分からない。
✕所有権や責任は立証できない: テキストの所有者、利用の適法性、開示義務の有無、責任の所在は判定できない。
✕ユーザーを特定しない: 個人・組織・アカウント・プロンプト・会話とテキストを結び付けない。
✕正確性は検証できない: 文章が真実か、誤解を招くか、有害か、適切な文脈かは判断できない。
✕非検出は人間の執筆を証明しない: 短すぎる、編集済み、翻訳済みのテキストや、非対応モデル・透かし導入前・他社ツールによる生成テキストでは検出できない場合がある。

開発者への影響 / ユースケース

🔧 API 利用者: 透明性要件に応じたオプトイン

API のテキスト透かしはデフォルト無効のため、既存の API 統合に自動的な変更はない。透明性義務やユーザー体験の要件に応じて、対象モデルで有効化を選択できる。クラウドサービス経由で OpenAI モデルを利用する場合も、数週間以内に透かしオプションが提供される予定。

🇪🇺 EU 向けサービス提供者: AI 法のコンテンツ透明性要件の確認

EU の ChatGPT / Codex ユーザー向け出力には数週間以内に不可視透かしが付与される。EU 向けにサービスを提供する開発者は、EU AI 法のコンテンツ透明性要件との関係を確認するとよい。

🔬 研究者・専門機関: 検出ツールの申請と textGrain の活用

検出ツールは一般公開されていないため、AI 生成テキストの判定機能をプロダクトに組み込みたい場合でも当面利用できない。研究者・専門機関は申請フォームから申請できる。textGrain はオープンソース化が予定されており、独自の透かし実装や研究の基盤として活用できる見込み。

まとめ

OpenAI は EU AI 法のテキスト来歴要件に対し、独自透かし技術 textGrain による段階的対応を開始した。API ではグローバルにオプトイン提供 (デフォルト無効)、EU 域内の ChatGPT / Codex では数週間以内に透かしを有効化し、検出ツールは当初、承認済み研究者・専門機関に限定して提供する。ベンチマークでは透かしによる出力品質の劣化は見られない一方、短文・低エントロピーな内容・編集後のテキストでは検出率が大きく低下するなど技術的限界は明確であり、OpenAI は「透かしが示さないこと」の周知を重視している。技術・標準・エビデンスの進展に応じてアプローチを見直し、検出ツールのアクセス拡大も検討するとしている。
